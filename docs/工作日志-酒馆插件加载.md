## 阶段 1：后端扩展管理器（M1）

### 已完成

- 新增 `flyai/extensions/`：
  - `models.py`：manifest / 兼容报告 / 安装记录，能力白名单 `KNOWN_CAPABILITIES`
  - `manifest.py`：字段校验（display_name、js/css 相对路径、version、hooks 函数名、loading_order、依赖、`flyai` 能力）
  - `scanner.py`：import 扫描 + 模块/符号缺口；内置 **38 个宿主模块**的符号表（与矩阵对齐）；`UI_RISK_MODULES` 识别 DOM 型依赖
  - `store.py`：`data/extensions/registry.json`、`installed/<name>/{files,manifest.json,compat-report.json}`、`data/<uid>/extensions/state.json`；原子写、设置 1MB 上限
  - `installer.py`：zip 安全解压（zip-slip / 符号链接 / 设备文件 / 重复路径 / 文件数 / 单文件 5MB / 解压总量），临时目录安装 + 原子替换 + 失败回滚；更新保留用户设置
  - `service.py`：列表、详情、安装/更新/卸载、启停、顺序、设置、host-state、按依赖过滤的启用快照
- 新增 `flyai/api/routes_extensions.py`：
  - `/api/extensions`、`/{name}`、`/enabled`、`/install`、`/{name}/update`、`DELETE`、`enable|disable`、`/order`、`/settings`、`/host-state`
  - 静态资源 `/scripts/extensions/third-party/{name}/{path}`：CORS `*`、nosniff、路径逐段校验、MIME 白名单
  - 权限：安装/更新/卸载默认 `min_level=256`（管理员）；普通用户仅启停/设置
- `config.py` 新增 `ExtensionSettings`（默认开启入口、安装仅管理员、网络默认关）
- `app.py` 初始化 `state.extensions`，注册 API 与静态路由
- `author/generate` 增加 `purpose="extension"`，供宿主的静默生成 RPC 复用
- 测试：`tests/test_extensions.py` 9 项（manifest、扫描、安装/启停/设置/快照、zip-slip、符号链接、更新保留设置、静态路径校验）
