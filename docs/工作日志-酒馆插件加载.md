## 阶段 1：后端扩展管理器（M1）

### 已完成

- 新增 `flyai/extensions/`：
  - `models.py`：manifest / 兼容报告 / 安装记录，能力白名单 `KNOWN_CAPABILITIES`
  - `manifest.py`：字段校验（display_name、js/css 相对路径、version、hooks 函数名、loading_order、依赖、`flyai` 能力）
  - `scanner.py`：import 扫描 + 模块/符号缺口；内置 **38 个宿主模块**的符号表（与矩阵对齐）；`UI_RISK_MODULES` 识别 DOM 型依赖
  - `store.py`：`data/extensions/registry.json`、`installed/<name>/{files,manifest.json,compat-report.json}`、`data/<uid>/extensions/state.json`；原子写、设置 1MB 上限
  - `installer.py`：zip 安全解压（zip-slip / 符号链接 / 设备文件 / 重复路径 / 文件数 / 单文件 5MB / 解压总量），临时目录安装 + 原子替换 + 失败回滚；更新保留用户设置
  - `service.py`：列表、详情、安装/更新/卸载、启停、顺序、设置、host-state、按依赖过滤的启用快照
- 新增 `flyai/api/routes_extensions.py`：
  - `/api/extensions`、`/{name}`、`/enabled`、`/install`、`/{name}/update`、`DELETE`、`enable|disable`、`/order`、`/settings`、`/host-state`
  - 静态资源 `/scripts/extensions/third-party/{name}/{path}`：CORS `*`、nosniff、路径逐段校验、MIME 白名单
  - 权限：安装/更新/卸载默认 `min_level=256`（管理员）；普通用户仅启停/设置
- `config.py` 新增 `ExtensionSettings`（默认开启入口、安装仅管理员、网络默认关）
- `app.py` 初始化 `state.extensions`，注册 API 与静态路由
- `author/generate` 增加 `purpose="extension"`，供宿主的静默生成 RPC 复用
- 测试：`tests/test_extensions.py` 9 项（manifest、扫描、安装/启停/设置/快照、zip-slip、符号链接、更新保留设置、静态路径校验）

## 阶段 3：L1 扩展宿主运行时（M2）

### 已完成

- `runtime/hostShims.ts`：iframe 内全局层
  - `eventSource`（on/once/off/makeFirst/makeLast/emit/emitAndWait/clear*，异步 handler 等待）
  - `extension_settings` + 500ms 防抖保存
  - `fetch`/XHR 拦截：同源走 `http.fetch`，外网走 `net.fetch`（宿主代理，无凭据）
  - `toastr`、`Popup`/`callGenericPopup`、宏替换
  - Slash 子系统：`SlashCommandParser.addCommandObject`、`SlashCommand.fromProps`、参数类型、Scope、管道 `|`、命名参数
- `runtime/modules.ts`：38 个宿主模块的 data: ESM 实现（与后端扫描表同源），含 `script.js` 的 `eventSource/event_types/setExtensionPrompt/generateQuietPrompt` 等 P0 符号、`utils.js` 30+ 纯函数、popup/constants/i18n/secrets/RossAscends/slash 全套
- `hostProtocol.ts`：消息校验（source/ns/version/≤256KB）、能力表、超时
- `hostDoc.ts`：CSP `connect-src 'none'`、import map（`origin/<path>` → data: 模块）、绝对入口 URL、activate hook
- `hostManager.ts`：按启用顺序挂载隐藏 iframe；RPC：
  - `settings.get/save`、`variables.get/set`、`chat.getMessages`、`generate.quiet/raw`
  - `worldbook.list/get`、`ui.toast/popup`、`net.fetch`、`http.fetch`、`template.render`
  - `slash.register/execute`（注册到宿主命令表）
  - 聊天事件转发：`CHAT_CHANGED`、`MESSAGE_SENT`、`MESSAGE_RECEIVED`、`GENERATION_STARTED/ENDED`
- `ExtensionHost` 挂到 `SessionView`；聊天输入 `/cmd` 优先命中扩展命令
- 测试：`extensionHost.test.ts` 6 项（协议校验、能力、模块导出完整性、宿主文档、异步事件、slash 管道）
