- 新增 `flyai/extensions/`：

  - `manifest.py`：字段校验（display_name、js/css 相对路径、version、hooks 函数名、loading_order、依赖、`flyai` 能力）
  - `scanner.py`：import 扫描 + 模块/符号缺口；内置 **38 个宿主模块**的符号表（与矩阵对齐）；`UI_RISK_MODULES` 识别 DOM 型依赖

  - 权限：安装/更新/卸载默认 `min_level=256`（管理员）；普通用户仅启停/设置
- `config.py` 新增 `ExtensionSettings`（默认开启入口、安装仅管理员、网络默认关）
- `app.py` 初始化 `state.extensions`，注册 API 与静态路由
- `author/generate` 增加 `purpose="extension"`，供宿主的静默生成 RPC 复用

## 阶段 5：L2/L3 分级收紧（2026-11-25）

- L3 判定从“仅 manifest.compat=ui”扩展为：导入 `RossAscends-mods.js`/`dragdrop.js`
  或直接 import `appendMediaToMessage`/`updateMessageBlock` 等 DOM 符号 → L3，禁止启用。
- `popup.js`/`scripts/chats.js` 归为 L2：允许加载但管理面板提示降级（弹窗走宿主 confirm，
  附件明确报不支持）。
- 新增测试：DOM fixture 安装为 L3 且 set_enabled 拒绝；popup fixture 为 L2 可启用
  （`tests/test_extensions.py` 14 passed）。
- L2 面板协议（schema/iframe）**尚未实现**；当前 L2 只是“可加载的降级逻辑扩展”。
