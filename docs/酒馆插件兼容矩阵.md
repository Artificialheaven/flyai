## 3. ST 内置扩展评估（静态，不含运行结果）

| 扩展类型 | 依赖 | 预计等级 | 说明 |
|---|---|---|---|
| 事件/变量/设置类（计数器、自动总结） | `script.js` | L1 | 可运行 |
| Slash 命令类 | `slash-commands/*` | L1 | 可运行（简单管道） |
| 静默生成类 | `generateQuietPrompt` | L1 | 走作者生成桥，受模型与权限限制 |
| 世界书读写类 | `world-info.js` | L1 | 读可用；写回落未实现 |
| 附件/数据银行 | `scripts/chats.js` | L2 | 明确报不支持 |
| 弹窗/设置面板 | `popup.js` + ST DOM | L2 | 弹窗可用；DOM 面板不可用 |
| 拖拽/Moving UI | `RossAscends-mods.js` | L3 | 明确不承诺 |
| 外部 API / 密钥 / 文件 | `secrets.js` / 网络 | L3 | 仅宿主代理白名单；密钥不可读 |

## 5. 结论

- L1 目标：fixture 与模块表已对齐，安装即可知道缺口；
- 未实现的符号在安装报告中列出，不会静默白屏；
- UI 型扩展明确标记 L2/L3，不承诺“装上就能跑”。
