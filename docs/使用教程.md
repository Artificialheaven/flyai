# FlyAI 使用教程

本文从零开始，帮你快速上手，并重点讲解**如何写出完善的角色卡与世界观**，让 AI 的扮演质量明显提升。

---

## 一、快速开始

1. **启动**
   ```bash
   .venv\Scripts\python main.py
   ```
   浏览器打开 <http://127.0.0.1:8000>。

2. **登录用户**
   打开工具会进入**独立登录页**（`/login`），**不登录无法进入**。手动输入用户名与密码登录（密码可留空；登录页不再提供用户点选清单）。登录成功后服务端签发随机登录令牌，存在浏览器本地；角色卡、世界观、会话都**按用户隔离**，不同用户名之间互不干扰；左下角「退出」会立即吊销令牌并回到登录页。**管理员账号与密码在 `config/config.json` 的 `auth.admin` 中设置**（首次默认 `admin` / 空密码，建议改掉）；**普通用户需由管理员在「用户管理」中创建**，不能自助注册（详见「多用户」一节）。

3. **配置 AI 提供商**
   点左侧「⚙️ 设置」→「提供商」→「＋ 新增提供商」，填入：
   - **ID**：任意唯一名（如 `deepseek`）
   - **类型**：`openai`（OpenAI 兼容，含 DeepSeek/Kimi/Qwen 等）或 `anthropic`
   - **Base URL**：如 `https://api.deepseek.com/v1`
   - **API Key**、**模型名**（如 `deepseek-chat`）
   - 勾选设为**激活**，点「保存」。

4. **新建会话**：点侧栏「＋」。然后就可以在底部输入框和 AI 对话了。

> `config/config.json` 里保存的是真实配置（含 API Key），不会入库；仓库只保留 `config.example.json`。

## 二、理解核心概念

| 概念 | 作用 |
|---|---|
| **会话** | 一段对话历史，可单独绑定一个角色 + 一个世界观 |
| **角色卡** | 你要扮演的那个角色：人设、经历、内容表 |
| **世界观** | 整个故事的设定：世界是什么样、有什么规则 |
| **内容表** | 角色卡/世界观各自附带的一张「标题→内容」资料库，AI 通过工具按需查询 |
| **属性跟踪** | 好感度、金钱这类会随剧情变化的值，AI 每回合可调用工具修改 |
| **对话格式** | 动作 / 内心活动 / 对白的书写规范，前端会分区着色显示 |

**最关键的一条**：会话顶栏有「角色」「世界观」两个下拉框。**选好角色与世界观后**，它们的人设、设定、内容表、要求才会注入这一次对话。

## 三、如何写出完善的角色卡

点左侧「🧩 内容」→「＋ 新建角色」。每个字段怎么填，直接决定扮演水平：

### 1. 角色名称
清晰、唯一的名字。建议同时给一个称号化名会更有质感，例如「爱丽丝 · 雾都旅者」。

### 2. 头像（可选）
点击头像框上传一张图片，会让界面更直观，不影响 AI 质量。

### 3. 【角色简介】——最重要的字段
一句话到一小段，说清这个角色**是谁、给人的第一印象、说话风格**。它决定了 AI 的基础人设。

> ❌ 差：「爱丽丝，女，二十岁。」
> ✅ 好：「一位冷静、毒舌却心地善良的年轻旅者，习惯用刻薄的玩笑掩饰受伤，面对陌生人的第一句话往往是嘲讽，但从不真的拒绝帮助他人。」

要点：
- **性格**（不只说职业/身份，说性格特质）
- **说话风格**（口头禅、语气、用词习惯）
- **态度倾向**（对主角是亲近、戒备还是疏远，可随剧情变化）
- **一个记忆锚点**（比如一个不愿提起的过去），让 AI 有东西可以深化

### 4. 【角色经历】——给角色的"过去"
写 2–6 段重要过往。它让 AI 的言行有来源，而不是凭空。建议包含：
- 出身与转折点（一次事件如何改变了她）
- 与主角（或这个世界）的既有关系
- 未解的心结或目标（让剧情有方向）

> 「出身海雾港的孤儿，十五岁那次遇难事件后患上惧水症，却故作洒脱地四处旅行，试图找到一个‘不必回头’的理由。与你说好同行一段路，实则在悄悄试探你是否可靠。」

### 5. 【对话范例 mes_example】——维持原创角色语气的关键
简介描述「她说话毒舌」，AI 往往只能写干巴巴的句子；直接给几轮**范例对白**，模仿质量会显著提升。

- 写 **3~5 轮**范例，轮与轮之间**单独一行写 `<START>`**。
- 用 `{{char}}` 代表本角色、`{{user}}` 代表用户，保存时会自动替换成实际名字。
- 范例可以包含动作、内心、口癖，越能体现节奏越好。

**示例：**
```
{{user}}：你怎么还没睡？
<START>
{{char}}：（没回头，手指敲着窗台）某人不来，我怎么敢睡。
<START>
{{user}}：嘴硬。
<START>
{{char}}：（轻笑一声）彼此彼此。
```

> 系统提示词会明确声明「范例剧情并未真实发生，仅供模仿语气、节奏与格式」，AI 不会把范例里的事当成已经发生过的剧情。

### 6. 【内容表】——AI 可按需查询的资料库
这是本工具的特色。内容表的每条 = **一个标题 + 一段内容 + 常驻勾选**。AI 随时可用 `query_lore` 工具查询（标题+正文多词打分；配了语义嵌入时先走带相似度门槛的向量检索，不达标自动回退关键词，结果默认上限 8 条）。

**怎么用最有效：**
- 把**会变化的细分设定**放进内容表，而不是塞进简介/经历，避免每次注入导致上下文膨胀。
- 标题要短而清晰，让 AI 能猜到关键词：`家庭`、`能力图谱`、`暗号`、`对主角的评价`、`关键事件真相`。
- **重要条目勾「常驻」**：勾选后无条件注入系统提示词（等同 SillyTavern 世界书 Constant）。适合「AI 绝不能忘」的铁则——因为 pull 模式下 AI 万一不调用 `query_lore`，没常驻的资料就等于不存在。常驻条目不宜多，多了会持续占用上下文。

**示例：**
| 标题 | 内容 | 常驻 |
|---|---|---|
| 铁则 | 绝不在任何人面前提起母亲的名字 | ✓ |
| 家庭 | 烟枪叶家族，父母双亡，与弟弟艾伦相依为命 | |
| 能力图谱 | 愈合之瞳（上限）、雾语术（进攻）、探知（辅助） | |
| 对主角的评价 | 起初戒备，发现对方守诺后逐步信任 | |
| 未解之谜 | 母亲留下的半张地图，指向雾都地下的古港 | |

> 技巧：内容写得越具体，AI 查出来用上的质量越高。避免「她很强」这种，改成「她的雾语术可将 20 米内的声响折叠，某次为保护队友连续使用导致脱力」。

### 7. 【对白格式要求】/【工具使用要求】
这两个文本框会**自动填入内置默认**。你可以为这个角色单独改写，比如强调她的口癖、不许用某类句式的规定等。留空则遵循全局默认。

## 四、如何写出完善的世界观

点「🧩 内容」→「＋ 新建世界观」。世界观提供的是**整场故事的规则与舞台**。

### 1. 【世界观内容】——世界的骨架
写清楚以下内容（不必长篇，重在有信息量）：
- **基础设定**：时间/地点/整体氛围或核心设定
- **运行规则**：这个世界最特殊的规则（魔法体系、科技水平、禁忌）
- **势力格局**：主要势力、阵营、矛盾
- **主角所处位置**：主角从哪出发、目标是什么

> 「雾都 · 利默，终年笼着能吞噬声响的灰雾。这里没有标准货币，一切交易以‘记忆’为筹码——每付一次价，就失去一段记忆碎片。铁匠行会垄断了记忆提炼术，城外的雾隐教视为亵渎。你是一个失去全部记忆的旅人，唯一线索是左臂上那枚雾色的印记。」

### 2. 【内容表】——世界的"细节词典"
和角色内容表一样按标题组织，AI 按需查询，并且同样可以勾「常驻」让铁则级设定始终在场。放**需要时才出现的具体设定**。

**示例：**
| 标题 | 内容 | 常驻 |
|---|---|---|
| 记忆交易铁则 | 失去的记忆无法复原，任何仪式都不行 | ✓ |
| 记忆货币 | 一枚记忆币 = 约三天的普通记忆；高价值记忆可铸成彩色币 | |
| 雾隐教 | 相信记忆是灵魂的一部分，主张归还，与铁匠行会对立 | |
| 灰雾 | 每小时随钟声涨落一次，雾中人会遗忘新近 10 分钟言行 | |
| 关键地点 | 旧钟塔、记忆交易所、雾台 | |

## 五、让扮演质量更高的小技巧

### 1. 分层"注入"而不是"倾倒"
- **永远在线的**：简介 + 经历 + 对话范例（每次对话都注入）→ 写最核心、最常用的人设与语气。
- **常驻条目**：勾了「常驻」的内容表条目也永远在线 → 只放不可违反的铁则。
- **按需查询的**：其余内容表条目（AI 需要才调 `query_lore`）→ 写分支细节、可变化设定。
- 这样上下文更省 token，AI 也更有"主动翻资料"的能力。
- **注入预算（默认关闭）**：「设置 → 角色扮演」里可给简介/经历/世界观/对话范例/常驻条目分别设字符上限，默认全是 **0=不限**，所以不填任何值时行为和旧版完全一致。超上限时按段落、整轮丢弃（**绝不截半轮**），末尾标「…（下略）」。一般只有提示词频繁超长时才需要设置。

### 2. 驱动工具使用
- 提示词中已教会 AI 在需要细节时调用 `query_lore`。当内容表足够有料时，AI 会主动查询，而不是瞎编。
- 设置 → 工具里可调「最大工具迭代轮数」（默认 8）、文件读取白名单目录。
- 工具栏执行会以**绿/红卡片**展示成功/失败状态；失败时 AI 会收到失败信息并自行纠错。

### 3. 对话格式与分区显示
默认开启「对白格式规范」：动作用 `（ ）`、内心活动用 `_…_`（下划线外侧不贴字母数字，不跨行）、对白用 `「」`，空行分段。前端会把**对白（蓝）、动作（斜体灰）、内心（彩色斜体）**区分显示，阅读体验更接近小说。旧的 `____…____` 语法仍兼容。
可在「设置 → 角色扮演」里开关，或为单个角色单独改写。

### 4. 属性跟踪
设置里可启用「属性跟踪」。默认定义了好感度、金钱。开启后 AI 会在**每回合结束**调用 `update_attributes` 增减这些值，顶栏实时显示。
- **由 AI 自行提供**：AI 自己根据剧情判断好感度怎么变。
- 关闭自动提供：AI 仅在剧情需要时调整。
- 也可以自己改 `config/config.json` 的 `roleplay.attributes.list` 增删属性及其范围。

### 5. 会话绑定
同一个角色可以配不同世界观产生不同故事；同一世界观也能配不同角色。会话顶栏随时切换。

### 6. 图生图：单张与多张参考图
发图给 AI 后可以让它改图：改风格、换装、改表情动作、局部修改、延展画面。一张图时直接说需求即可（如「把这张换成水彩风」），AI 自动以最近的图为参考。

需要**多张图配合**时（换装、把人物放进另一张图的场景、融合两人长相、参考多角度姿态等）：

1. 按顺序发图（或在对话里指出要用的图），直接说明每张图的角色，例如：
   「把第一张人物的服装换成第二张的服装，保留第一张的面孔和姿势」
   「把图1的人物放进图2的夜景街道」。
2. AI 会按「图1、图2…」组织提示词，参考图最多 **14 张**；图片先后顺序与编号严格一致。
3. 历史里图片不够时 AI 会直接说明缺几张，不会拿错图硬画。

### 7. 本地 Stable Diffusion 生图（Anything V5）
除了云端生图模型，还可以使用本机部署的 Stable Diffusion WebUI（如装载 Anything V5 的 Forge/重绘 WebUI），**无需以 `--api` 启动**——FlyAI 直接走 WebUI 的 Gradio 接口。

1. 管理员在「⚙️ 设置 → Stable Diffusion」勾选「启用」，确认 WebUI 地址（默认 `http://127.0.0.1:7860`）后保存。
2. 对话输入区左侧出现 **「SD」按钮**：点亮即切换为 SD 引擎（选择会记住，刷新不丢），熄灭则仍走云端生图模型。
3. 引擎点亮时让 AI 画图，AI 不直接写 SD 提示词，而是由**内置的提示词 AI** 根据画面描述自动生成：
   - 英文 danbooru 标签提示词（画质标签开头，含主体/服饰/动作/场景/镜头/光线，必要时自动使用权重语法）；
   - 负向提示词（通用崩坏词 + 按画面追加的针对性负向词）；
   - 全部采样参数：宽高（自动 8 的倍数）、步数、CFG、采样器与调度器、随机种子。
4. 参数兜底：设置中可以改宽高、步数、CFG、采样器、负向词的默认值；内置 AI 漏写或越界的参数会自动回落到这些默认值。

> 如果更换了 WebUI 版本导致报「SD 未返回图片」，文生图的函数编号可能变了：可在 WebUI 的 `/info` 里找到参数含 Prompt/Negative prompt、返回 Gallery 的 `fn_index`，填回设置。

### 8. 点击图片放大 / 下载 / 查看提示词
对话中**任意图片**（自己上传的、AI 生成的、图生图结果）点击即进入全屏查看器：

- 右上角 **⬇ 下载**：按原始文件名保存图片；
- **📝 提示词**：打开侧边面板（手机端为底部抽屉），按生图方式分别展示：
  - **Stable Diffusion**：正/负向提示词（等宽字体、可一键复制）+ 尺寸、步数、CFG、采样器、调度器、种子等参数网格；
  - **云端生图**：模型与分辨率标签 + 完整中文提示词；
  - **云端图生图**：标题区分，展示成图提示词、参考图缩略图（编号图1、图2，点击可放大）；
  - 用户上传的图片无提示词数据时，不显示「提示词」按钮。
- 点击图片外黑色区域或按 **Esc** 关闭（Esc 先收起信息面板，再关查看器）。

> 💡 手机端顶栏占三行较挤：点顶栏右上角 **⌃** 可折叠为只显示 ☰ + 会话标题的细条（再点 ⌄ 恢复），折叠状态会记住；桌面端不显示该按钮。

### 9. Token 用量统计
顶栏的 **🪙 token 标签**始终显示（未使用时为 `0 tokens`）该会话自创建以来的**累计总 token**——不区分单轮、刷新页面或换设备登录都不会清零（与会话一起持久保存）；鼠标悬停（手机长按标题栏可在浏览器中查看）可见精确总数及输入/输出明细。数量过千时自动缩写：`10.5k tokens`，过百万时显示 `7M tokens`。每轮结束时仍有 toast 提示当轮输入/输出用量。

### 10. 对话压缩：先看 diff，确认才写入
长对话可以让 AI 把剧情归纳进角色卡/世界观。流程是：

1. 顶栏点「☁ 压缩」→ AI 生成**提案**，弹窗里逐项展示变更：
   - 绿色＝新增条目/新增文字，红色＝被改写的文字，灰色「N 条未变（含常驻 M 条）」默认折叠；
   - 群聊房间按参与者折叠分区，世界观点单独区块。
2. **确认之前什么都不写**：点「放弃」或直接关闭，会话没有任何改动。
3. 点「✓ 确认写入」后才写入**当前会话副本**（角色库主卡不受影响）；之后才可下载压缩包、单 AI 会话还能发布回角色库。细改请在写入后用会话副本编辑器完成。
4. 内容表**按标题合并**：AI 漏列的条目原样保留，不会丢设定；提案生成后若设定又被改过，写入会失败（提示重新压缩），提案不会被错误套用。

### 11. AI 浏览器：让 AI 像人一样逐级翻网页

普通 web_fetch 不执行 JavaScript，遇到动态网页只能拿到空壳。安装 Playwright 后，AI 可以操控真实浏览器：

1. 安装（一次性）：
   ```
   pip install -r requirements-browser.txt
   playwright install chromium
   ```
   Ubuntu 另需 `sudo playwright install-deps chromium`；无头模式不需要桌面环境。
2. 「⚙️ 设置 → AI 浏览器」勾选启用，**重启服务**生效。
3. AI 会获得 7 个工具：`browser_open`（打开网址）、`browser_snapshot`（查看当前页）、`browser_click`（点编号元素）、`browser_type`（填输入框，可直接提交）、`browser_back`、`browser_get_text`、`browser_close`。
4. 典型流程：「打开搜索页 → 输入关键词回车 → 在结果页点第 2 条 → 进入详情页 → browser_get_text 读正文」。每次动作后 AI 都会自动收到带元素编号的新页面快照，所以能逐级深入而不迷路。

注意：浏览器会拦截一切指向内网/本机的请求（包括页面 JS 自己发出的），空闲会话自动关闭标签页，单次会话动作数有上限（默认 15）。

## 六、导出 / 导入角色与世界

- 在「🧩 内容」列表里，每个角色/世界都有**导出**按钮 → 把卡片保存为 `.json` 文件，方便备份或分享。
- 列表顶部有**导入**按钮 → 选择 `.json` 文件即可载入（导入会生成新 ID，不覆盖现有卡片）。
- 导出文件内含该卡片的全部信息（含要求字段）。**注意**：头像引用的是本机路径，导入到另一台机器时头像可能不显示，可重新上传。

## 七、多用户（登录页 + 管理员）

- 打开即进入**独立登录页 `/login`**，手动输入用户名密码，验证通过才可进入主界面（不登录进不去）。左下角显示当前用户，「退出」立即吊销令牌、回到登录页。
- **登录令牌**：登录成功后服务端签发随机不透明令牌（有效期 7 天），浏览器存 localStorage，服务端同时持久化到 `data/auth_sessions.json`——**刷新页面、重启服务都不掉登录态**。之后所有数据请求都带 `Authorization: Bearer <令牌>`，仅凭用户名（包括 `X-User-Id: admin`）不再能访问任何接口。
- **登录限速**：同一 IP + 用户名连续 **5 次密码错误即锁定 5 分钟**，锁定期间即使密码正确也会被拒（HTTP 429）；用户不存在同样计入失败，无法据此试探用户名。
- **管理员与普通用户分开**：
  - **管理员**：账号凭据写在 `config/config.json` 的 `auth.admin`（`username` / `password`）。**没有自动创建的任何默认用户**，管理员是谁完全由你在这份配置里决定。建议设一个真实密码，并妥善保管。
  - **普通用户**：存在 `data/users.json`，**不能自助注册**，只能由管理员在侧栏「👥 用户管理」中创建；管理员也可在此修改等级、删除用户。
- **管理员重置用户密码**：「👥 用户管理」每个用户行点「🔑 改密」，行内输入新密码（留空表示无密码）确认即可。重置后**该用户的现有登录会话立即全部失效**，需用新密码重新登录。
- **不登录不能进入**：不提供有效令牌就无法进入主界面或访问任何数据接口。
- 数据（角色卡、世界观、会话、上传头像）**按用户完全隔离**（管理员与各普通用户各有独立目录）。
- 提供商、插件、全局工具设置是**所有用户共享**的（本地工具的一面）。
- 切换用户 / 删除用户都不会影响其他用户的数据。

## 八、常见问题

- **AI 不查询内容表？** → 检查会话顶栏是否已选角色/世界观；内容表条目标题是否够具体；工具是否在设置中启用。关键设定可直接勾「常驻」强制注入，不依赖 AI 主动查询。
- **AI 的语气不像角色？** → 在角色卡「对话范例」里给 3~5 轮带动作、口癖的 `<START>` 分隔范例，比在简介里写性格描述有效得多。
- **想用两张图配合改图（换装/换场景）？** → 按顺序发图并说明「第一张…第二张…」，AI 会把两张都作为参考（最多 14 张）；若它只参考了一张，明确要求「两张都要用，图1是人物、图2是服装」即可。
- **压缩后担心 AI 漏了设定？** → 内容表按标题合并，漏列的条目原样保留；且确认前可完整查看 diff，放弃即不写入。
- **AI 抓的网页太长，后面的内容看得到吗？** → 可以。web_fetch 分页返回（默认每次 6000 字），AI 需要后续内容时用相同 URL 加 `offset=6000`、`offset=12000` 继续读，直到页面末尾；翻页读的是服务端缓存，不会重复下载。
- **设置了预算后想恢复全量注入？** → 把对应预算改回 0 即可，0=不限。
- **属性不动？** → 确认设置里已开启「属性跟踪」且在会话中选择了角色/世界观；提示词里说明了每回合结束更新。
- **历史刷新后工具卡片状态不对？** → 新版已把工具的成功/失败状态持久化进会话消息（`ok` 字段），旧会话按内容前缀智能推断。
- **忘记某个用户密码？** → 让管理员在「👥 用户管理 → 🔑 改密」直接重置；也可以在 `data/users.json` 里把该用户的 `password_hash` 清空，留空密码即视为任意输入可进。
- **忘记管理员密码？** → 直接编辑 `config/config.json` 的 `auth.admin.password`，改成一个你知道的即可（本地工具，重启后生效）。
- **登录提示“用户名或密码错误”？** → 新版不区分用户名是否存在（防止枚举）。管理员账号请用 `config` 中 `auth.admin` 设置的 `username`；普通用户需由管理员在「👥 用户管理」中创建。
- **登录提示“登录失败次数过多，请 N 秒后再试”？** → 该 IP + 用户名连续 5 次失败已被锁定，等倒计时结束再试。
