# FlyAI 使用教程

本文从零开始，帮你快速上手，并重点讲解**如何写出完善的角色卡与世界观**，让 AI 的扮演质量明显提升。

---

## 一、快速开始

1. **启动**
   ```bash
   .venv\Scripts\python main.py
   ```
   浏览器打开 <http://127.0.0.1:8000>。

2. **登录用户**
   打开工具会进入**独立登录页**（`/login`），**不登录无法进入**。手动输入用户名与密码登录（密码可留空；登录页不再提供用户点选清单）。登录成功后服务端签发随机登录令牌，存在浏览器本地；角色卡、世界观、会话都**按用户隔离**，不同用户名之间互不干扰；左下角「退出」会立即吊销令牌并回到登录页。**管理员账号与密码在 `config/config.json` 的 `auth.admin` 中设置**（首次默认 `admin` / 空密码，建议改掉）；**普通用户需由管理员在「用户管理」中创建**，不能自助注册（详见「多用户」一节）。

3. **配置 AI 提供商**
   点左侧「⚙️ 设置」→「提供商」→「＋ 新增提供商」，填入：
   - **ID**：任意唯一名（如 `deepseek`）
   - **类型**：`openai`（OpenAI 兼容，含 DeepSeek/Kimi/Qwen 等）或 `anthropic`
   - **Base URL**：如 `https://api.deepseek.com/v1`
   - **API Key**、**模型名**（如 `deepseek-chat`）
   - 勾选设为**激活**，点「保存」。

4. **新建会话**：点侧栏「＋」。然后就可以在底部输入框和 AI 对话了。

> `config/config.json` 里保存的是真实配置（含 API Key），不会入库；仓库只保留 `config.example.json`。

## 二、理解核心概念

| 概念 | 作用 |
|---|---|
| **会话** | 一段对话历史，可单独绑定一个角色 + 一个世界观 |
| **角色卡** | 你要扮演的那个角色：人设、经历、内容表 |
| **世界观** | 整个故事的设定：世界是什么样、有什么规则 |
| **内容表** | 角色卡/世界观各自附带的一张「标题→内容」资料库，AI 通过工具按需查询 |
| **属性跟踪** | 好感度、金钱这类会随剧情变化的值，AI 每回合可调用工具修改 |
| **对话格式** | 动作 / 内心活动 / 对白的书写规范，前端会分区着色显示 |

**最关键的一条**：会话顶栏有「角色」「世界观」两个下拉框。**选好角色与世界观后**，它们的人设、设定、内容表、要求才会注入这一次对话。

## 三、如何写出完善的角色卡

点左侧「🧩 内容」→「＋ 新建角色」。每个字段怎么填，直接决定扮演水平：

### 1. 角色名称
清晰、唯一的名字。建议同时给一个称号化名会更有质感，例如「爱丽丝 · 雾都旅者」。

### 2. 头像（可选）
点击头像框上传一张图片，会让界面更直观，不影响 AI 质量。

### 3. 【角色简介】——最重要的字段
一句话到一小段，说清这个角色**是谁、给人的第一印象、说话风格**。它决定了 AI 的基础人设。

> ❌ 差：「爱丽丝，女，二十岁。」
> ✅ 好：「一位冷静、毒舌却心地善良的年轻旅者，习惯用刻薄的玩笑掩饰受伤，面对陌生人的第一句话往往是嘲讽，但从不真的拒绝帮助他人。」

要点：
- **性格**（不只说职业/身份，说性格特质）
- **说话风格**（口头禅、语气、用词习惯）
- **态度倾向**（对主角是亲近、戒备还是疏远，可随剧情变化）
- **一个记忆锚点**（比如一个不愿提起的过去），让 AI 有东西可以深化

### 4. 【角色经历】——给角色的"过去"
写 2–6 段重要过往。它让 AI 的言行有来源，而不是凭空。建议包含：
- 出身与转折点（一次事件如何改变了她）
- 与主角（或这个世界）的既有关系
- 未解的心结或目标（让剧情有方向）

> 「出身海雾港的孤儿，十五岁那次遇难事件后患上惧水症，却故作洒脱地四处旅行，试图找到一个‘不必回头’的理由。与你说好同行一段路，实则在悄悄试探你是否可靠。」

### 5. 【对话范例 mes_example】——维持原创角色语气的关键
简介描述「她说话毒舌」，AI 往往只能写干巴巴的句子；直接给几轮**范例对白**，模仿质量会显著提升。

- 写 **3~5 轮**范例，轮与轮之间**单独一行写 `<START>`**。
- 用 `{{char}}` 代表本角色、`{{user}}` 代表用户，保存时会自动替换成实际名字。
- 范例可以包含动作、内心、口癖，越能体现节奏越好。

**示例：**
```
{{user}}：你怎么还没睡？
<START>
{{char}}：（没回头，手指敲着窗台）某人不来，我怎么敢睡。
<START>
{{user}}：嘴硬。
<START>
{{char}}：（轻笑一声）彼此彼此。
```

> 系统提示词会明确声明「范例剧情并未真实发生，仅供模仿语气、节奏与格式」，AI 不会把范例里的事当成已经发生过的剧情。

### 6. 【内容表】——AI 可按需查询的资料库
这是本工具的特色。内容表的每条 = **一个标题 + 一段内容 + 常驻勾选**。AI 随时可用 `query_lore` 工具查询（标题+正文多词打分；配了语义嵌入时先走带相似度门槛的向量检索，不达标自动回退关键词，结果默认上限 8 条）。

**怎么用最有效：**
- 把**会变化的细分设定**放进内容表，而不是塞进简介/经历，避免每次注入导致上下文膨胀。
- 标题要短而清晰，让 AI 能猜到关键词：`家庭`、`能力图谱`、`暗号`、`对主角的评价`、`关键事件真相`。
- **重要条目勾「常驻」**：勾选后无条件注入系统提示词（等同 SillyTavern 世界书 Constant）。适合「AI 绝不能忘」的铁则——因为 pull 模式下 AI 万一不调用 `query_lore`，没常驻的资料就等于不存在。常驻条目不宜多，多了会持续占用上下文。

**示例：**
| 标题 | 内容 | 常驻 |
|---|---|---|
| 铁则 | 绝不在任何人面前提起母亲的名字 | ✓ |
| 家庭 | 烟枪叶家族，父母双亡，与弟弟艾伦相依为命 | |
| 能力图谱 | 愈合之瞳（上限）、雾语术（进攻）、探知（辅助） | |
| 对主角的评价 | 起初戒备，发现对方守诺后逐步信任 | |
| 未解之谜 | 母亲留下的半张地图，指向雾都地下的古港 | |

> 技巧：内容写得越具体，AI 查出来用上的质量越高。避免「她很强」这种，改成「她的雾语术可将 20 米内的声响折叠，某次为保护队友连续使用导致脱力」。

### 7. 【对白格式要求】/【工具使用要求】
这两个文本框会**自动填入内置默认**。你可以为这个角色单独改写，比如强调她的口癖、不许用某类句式的规定等。留空则遵循全局默认。

## 四、如何写出完善的世界观

点「🧩 内容」→「＋ 新建世界观」。世界观提供的是**整场故事的规则与舞台**。

### 1. 【世界观内容】——世界的骨架
写清楚以下内容（不必长篇，重在有信息量）：
- **基础设定**：时间/地点/整体氛围或核心设定
- **运行规则**：这个世界最特殊的规则（魔法体系、科技水平、禁忌）
- **势力格局**：主要势力、阵营、矛盾
- **主角所处位置**：主角从哪出发、目标是什么

> 「雾都 · 利默，终年笼着能吞噬声响的灰雾。这里没有标准货币，一切交易以‘记忆’为筹码——每付一次价，就失去一段记忆碎片。铁匠行会垄断了记忆提炼术，城外的雾隐教视为亵渎。你是一个失去全部记忆的旅人，唯一线索是左臂上那枚雾色的印记。」

### 2. 【内容表】——世界的"细节词典"
和角色内容表一样按标题组织，AI 按需查询，并且同样可以勾「常驻」让铁则级设定始终在场。放**需要时才出现的具体设定**。

**示例：**
| 标题 | 内容 | 常驻 |
|---|---|---|
| 记忆交易铁则 | 失去的记忆无法复原，任何仪式都不行 | ✓ |
| 记忆货币 | 一枚记忆币 = 约三天的普通记忆；高价值记忆可铸成彩色币 | |
| 雾隐教 | 相信记忆是灵魂的一部分，主张归还，与铁匠行会对立 | |
| 灰雾 | 每小时随钟声涨落一次，雾中人会遗忘新近 10 分钟言行 | |
| 关键地点 | 旧钟塔、记忆交易所、雾台 | |

## 五、让扮演质量更高的小技巧

### 1. 分层"注入"而不是"倾倒"
- **永远在线的**：简介 + 经历 + 对话范例（每次对话都注入）→ 写最核心、最常用的人设与语气。
- **常驻条目**：勾了「常驻」的内容表条目也永远在线 → 只放不可违反的铁则。
- **按需查询的**：其余内容表条目（AI 需要才调 `query_lore`）→ 写分支细节、可变化设定。
- 这样上下文更省 token，AI 也更有"主动翻资料"的能力。
- **注入预算（默认关闭）**：「设置 → 角色扮演」里可给简介/经历/世界观/对话范例/常驻条目分别设字符上限，默认全是 **0=不限**，所以不填任何值时行为和旧版完全一致。超上限时按段落、整轮丢弃（**绝不截半轮**），末尾标「…（下略）」。一般只有提示词频繁超长时才需要设置。

### 2. 驱动工具使用
- 提示词中已教会 AI 在需要细节时调用 `query_lore`。当内容表足够有料时，AI 会主动查询，而不是瞎编。
- 设置 → 工具里可调「最大工具迭代轮数」（默认 8）、文件读取白名单目录。
- 工具栏执行会以**绿/红卡片**展示成功/失败状态；失败时 AI 会收到失败信息并自行纠错。

### 3. 对话格式与分区显示
默认开启「对白格式规范」：动作用 `（ ）`、内心活动用 `_…_`（下划线外侧不贴字母数字，不跨行）、对白用 `「」`，空行分段。前端会把**对白（蓝）、动作（斜体灰）、内心（彩色斜体）**区分显示，阅读体验更接近小说。旧的 `____…____` 语法仍兼容。
可在「设置 → 角色扮演」里开关，或为单个角色单独改写。

### 4. 属性跟踪
设置里可启用「属性跟踪」。默认定义了好感度、金钱。开启后 AI 会在**每回合结束**调用 `update_attributes` 增减这些值，顶栏实时显示。
- **由 AI 自行提供**：AI 自己根据剧情判断好感度怎么变。
- 关闭自动提供：AI 仅在剧情需要时调整。
- 也可以自己改 `config/config.json` 的 `roleplay.attributes.list` 增删属性及其范围。

### 5. 会话绑定
同一个角色可以配不同世界观产生不同故事；同一世界观也能配不同角色。会话顶栏随时切换。

### 6. 图生图：单张与多张参考图
发图给 AI 后可以让它改图：改风格、换装、改表情动作、局部修改、延展画面。一张图时直接说需求即可（如「把这张换成水彩风」），AI 自动以最近的图为参考。

需要**多张图配合**时（换装、把人物放进另一张图的场景、融合两人长相、参考多角度姿态等）：

1. 按顺序发图（或在对话里指出要用的图），直接说明每张图的角色，例如：
   「把第一张人物的服装换成第二张的服装，保留第一张的面孔和姿势」
   「把图1的人物放进图2的夜景街道」。
2. AI 会按「图1、图2…」组织提示词，参考图最多 **14 张**；图片先后顺序与编号严格一致。
3. 历史里图片不够时 AI 会直接说明缺几张，不会拿错图硬画。

云端生图模型支持三种接口类型（「设置 → 模型 → 生图」新建时选择）：

- **火山方舟 / Seedream**：默认类型，走 `/images/generations` 的 `image` 字段，支持 data URI 与裸 base64 两种参考图形态；
- **OpenAI 图片接口**：`gpt-image-1`、`dall-e-3` 等，文生图走 `/images/generations`（兼容 `b64_json` 与 `url` 返回），图生图走 `/images/edits` 的 multipart 上传；
- **Google Gemini / Imagen**：Gemini 图片模型走 `:generateContent`（参考图放 `inline_data`，兼容 `inlineData` 返回），Imagen 走 `:predict`。

API Key 可以留空（本地或免鉴权网关），此时不会发送 `Authorization` / `x-api-key` / `x-goog-api-key` 头。尺寸：Ark 用 `1K/2K/4K`，OpenAI 自动映射为像素尺寸，Gemini 3 系列按 `imageSize` 传，2.5 系列忽略尺寸。

### 7. 本地 Stable Diffusion 生图（Anything V5）
除了云端生图模型，还可以使用本机部署的 Stable Diffusion WebUI（如装载 Anything V5 的 Forge/重绘 WebUI），**无需以 `--api` 启动**——FlyAI 直接走 WebUI 的 Gradio 接口。

1. 管理员在「⚙️ 设置 → Stable Diffusion」勾选「启用」，确认 WebUI 地址（默认 `http://127.0.0.1:7860`）后保存。
2. 对话输入区左侧出现 **「SD」按钮**：点亮即切换为 SD 引擎（选择会记住，刷新不丢），熄灭则仍走云端生图模型。
3. 引擎点亮时让 AI 画图，AI 不直接写 SD 提示词，而是由**内置的提示词 AI** 根据画面描述自动生成：
   - 英文 danbooru 标签提示词（画质标签开头，含主体/服饰/动作/场景/镜头/光线，必要时自动使用权重语法）；
   - 负向提示词（通用崩坏词 + 按画面追加的针对性负向词）；
   - 全部采样参数：宽高（自动 8 的倍数）、步数、CFG、采样器与调度器、随机种子。
4. 参数兜底：设置中可以改宽高、步数、CFG、采样器、负向词的默认值；内置 AI 漏写或越界的参数会自动回落到这些默认值。

> 如果更换了 WebUI 版本导致报「SD 未返回图片」，文生图的函数编号可能变了：可在 WebUI 的 `/info` 里找到参数含 Prompt/Negative prompt、返回 Gallery 的 `fn_index`，填回设置。

### 8. 点击图片放大 / 下载 / 查看提示词
对话中**任意图片**（自己上传的、AI 生成的、图生图结果）点击即进入全屏查看器：

- 右上角 **⬇ 下载**：按原始文件名保存图片；
- **📝 提示词**：打开侧边面板（手机端为底部抽屉），按生图方式分别展示：
  - **Stable Diffusion**：正/负向提示词（等宽字体、可一键复制）+ 尺寸、步数、CFG、采样器、调度器、种子等参数网格；
  - **云端生图**：模型与分辨率标签 + 完整中文提示词；
  - **云端图生图**：标题区分，展示成图提示词、参考图缩略图（编号图1、图2，点击可放大）；
  - 用户上传的图片无提示词数据时，不显示「提示词」按钮。
- 点击图片外黑色区域或按 **Esc** 关闭（Esc 先收起信息面板，再关查看器）。

> 💡 手机端顶栏占三行较挤：点顶栏右上角 **⌃** 可折叠为只显示 ☰ + 会话标题的细条（再点 ⌄ 恢复），折叠状态会记住；桌面端不显示该按钮。

### 9. Token 用量统计
顶栏的 **🪙 token 标签**始终显示（未使用时为 `0 tokens`）该会话自创建以来的**累计总 token**——不区分单轮、刷新页面或换设备登录都不会清零（与会话一起持久保存）；鼠标悬停（手机长按标题栏可在浏览器中查看）可见精确总数及输入/输出明细。数量过千时自动缩写：`10.5k tokens`，过百万时显示 `7M tokens`。每轮结束时仍有 toast 提示当轮输入/输出用量。

### 10. 对话压缩：先看 diff，确认才写入
长对话可以让 AI 把剧情归纳进角色卡/世界观。流程是：

1. 顶栏点「☁ 压缩」→ AI 生成**提案**，弹窗里逐项展示变更：
   - 绿色＝新增条目/新增文字，红色＝被改写的文字，灰色「N 条未变（含常驻 M 条）」默认折叠；
   - 群聊房间按参与者折叠分区，世界观点单独区块。
2. **确认之前什么都不写**：点「放弃」或直接关闭，会话没有任何改动。
3. 点「✓ 确认写入」后才写入**当前会话副本**（角色库主卡不受影响）；之后才可下载压缩包、单 AI 会话还能发布回角色库。细改请在写入后用会话副本编辑器完成。
4. 内容表**按标题合并**：AI 漏列的条目原样保留，不会丢设定；提案生成后若设定又被改过，写入会失败（提示重新压缩），提案不会被错误套用。

### 11. AI 浏览器：让 AI 像人一样逐级翻网页

普通 web_fetch 不执行 JavaScript，遇到动态网页只能拿到空壳。安装 Playwright 后，AI 可以操控真实浏览器：

1. 安装（一次性）：
   ```
   pip install -r requirements-browser.txt
   playwright install chromium
   ```
   Ubuntu 另需 `sudo playwright install-deps chromium`；无头模式不需要桌面环境。
2. 「⚙️ 设置 → AI 浏览器」勾选启用，保存后立即生效（浏览器在首次使用时自动启动）。
3. AI 会获得 7 个工具：`browser_open`（打开网址）、`browser_snapshot`（查看当前页）、`browser_click`（点编号元素）、`browser_type`（填输入框，可直接提交）、`browser_back`、`browser_get_text`、`browser_close`。
4. 典型流程：「打开搜索页 → 输入关键词回车 → 在结果页点第 2 条 → 进入详情页 → browser_get_text 读正文」。每次动作后 AI 都会自动收到带元素编号的新页面快照，所以能逐级深入而不迷路。

注意：浏览器会拦截一切指向内网/本机的请求（包括页面 JS 自己发出的），空闲会话自动关闭标签页，单次会话动作数有上限（默认 15）。

### 12. 联网搜索：Chromium / 直连两种引擎

AI 调用 `web_search` 时的搜索执行方式可以在「⚙️ 设置 → 联网搜索」里选择：

1. **Chromium 浏览器（默认）**：分两级——
   - **Bing 优先走 RSS 数据接口**（搜索 URL 加 `&format=rss`，httpx 直连拿到干净 XML），不启动浏览器，速度与直连相当，也没有页面渲染竞态；
   - RSS 不可用（网络异常、返回非 XML）时自动改用 Playwright Chromium 真实打开搜索页（需先按第 11 节安装），反爬更稳，代价是慢 2~5 秒；浏览器进程只启动一次、全局复用，每次搜索使用独立隐身上下文、用完即关。
2. **httpx 直连**：服务端直接请求 Bing 搜索页 HTML 并解析，速度快、无需安装任何额外组件；个别网络环境下可能被搜索引擎限流。

搜索引擎可选 **Bing（默认）** 或**百度**：

- 百度仅在 Chromium 方式下可用（直连方式选百度会在搜索时收到明确提示）；
- 百度结果中的 `baidu.com/link?url=` 跳转链会自动解包为真实网址；
- 百度返回「安全验证 / 验证码」时**自动改用 Bing 重搜**，并在结果开头注明，AI 不会拿到空结果。

搜索代理、结果条数、正文长度上限等设置仍在同一处配置；修改设置后已启动的浏览器会自动按新配置重建。

### 13. 语音合成：让 AI 把内容念出来

除了文字，AI 还可以把内容**朗读成语音**。你说「朗读一下这段 / 用语音说 / 念出来 / 读一遍」，AI 就会调用 `text_to_speech` 工具生成一条语音，在它的消息卡片里以独立语音条展示。

**首次使用前的配置**（管理员在「⚙️ 设置 → 语音合成」）：

1. 在火山引擎控制台开通「豆包语音合成」，把 API Key 填入（`X-Api-Key`）；
2. 资源版本默认 `seed-tts-2.0`——它只能调用「语音合成模型 2.0」的音色；音色需要在控制台确认已授权；
3. **音色清单**：点「＋ 添加音色」录入「显示名 + 音色 ID」（如「鲸鱼娘 / S_NkpD5org2」），清单是角色卡下拉绑定的数据源；默认音色 ID 在下方单独填写，允许是清单外的 ID；
4. **语音合成最低权限等级**：填 0 表示不限制；填 1–255 则只有达到该等级的用户（及管理员，管理员恒可用）才能合成；
5. 保存配置后**立即生效**，无需重启服务。

**给角色卡绑定音色**：在「🧩 内容」里编辑角色卡，「绑定音色」下拉从音色清单中选择即可；留空表示使用全局默认音色。已绑定的角色说话时自动使用该音色；你也可以在对话里临时要求「换个声音说」，AI 显式指定的音色优先于绑定值。

**语音条的操作**：

- 点左侧圆形按钮播放/暂停；点进度条任意位置跳转到该处；右侧显示「已播放 / 总时长」；
- ⤓ 按钮可把音频下载到本地；同一页面播放新语音时，其他语音会自动暂停；
- 长文本 AI 会自动分成多条语音依次生成（单条上限 1000 字）。

**音频格式**：默认 mp3，浏览器兼容性最好；选 `ogg_opus` 会存为 `.ogg`；选 `pcm` 服务端会自动封装成 `.wav` 再展示，三者都可以直接播放。代理仅支持 HTTP 代理（`http://`），不支持 socks5；代理留空为直连。

**常见报错**：

- 提示「音色未授权」（错误码 45000000）：到控制台确认音色已授权，且音色与资源版本匹配（2.0 音色配 `seed-tts-2.0`）；
- 提示「音色与资源版本不匹配」（错误码 55000000）：该音色不属于当前资源版本，更换音色 ID 或切换到匹配的资源版本；
- 提示「并发数超限」：同一资源的并发合成达到上限，稍等片刻再试；
- 提示「权限等级不足（语音合成需要 LvN，当前 LvM）」：你的账号等级低于管理员设置的门槛，请联系管理员提升等级；
- 握手失败：检查 API Key 是否正确、资源版本是否已开通（提示「未获得该资源版本的授权」时需先在控制台开通）；
- 合成超时：可在设置里调大超时时间（`tts.timeout_seconds`）。

### 14. Galgame 模式：全屏视觉小说

新建会话时勾选「🎮 Galgame 模式」，**必须且只能选择一个角色卡**，确认后进入全屏视觉小说界面。该模式第一期仅支持单角色，不支持群聊。

**玩法流程**：

1. **故事的开端**：新会话没有历史，先在输入框写下初始剧情——你是谁、身在何处、发生了什么（如「黄昏，我推开了旧校舍音乐教室的门……」），点「开始故事」；
2. AI 据此先**绘制背景**（横版场景、无人物），再以角色卡头像为参考**绘制全身立绘**（纯绿幕底，系统自动抠像叠加），画面到位后开始演出；
3. 底部对话框逐句显示：对白去引号、白色；动作（括号内容）蓝色；内心独白紫色斜体；叙述浅色。AI 写完一段后，会**先把整段所有对白的语音全部合成好**——这期间对话框显示「角色思考中…」；全部就绪后才开始逐句演出：每句**语音和打字机文字同时出现**。关闭喇叭则直接打字机；
4. 每段结束后画面上出现 **2–4 个选项**按钮：点选项直接推进；也可点「✎ 自己输入」展开输入框，输入自定义的行动或台词；
5. AI 若未给选项，会显示「接下来……」自由输入框，随时可以继续写剧情。

**点击节奏**：每句话演出完毕后都会**停住等你点击**，不会自动连播——像读视觉小说一样自己掌握节奏。「角色思考中」等待时点击 → 不再等待、直接开始演出（未就绪的句子会在该句前稍等）；打字机演出中点击 → 当前句子立即补全（语音继续播放）；句子已完整后点击 → 进入下一句。整段对话全部结束后，选项才会弹出来。

**语音只合成一次**：每句对白的语音合成后会保存在本会话里，刷新页面或退出再进入时，已经合成过的句子直接播放已保存的音频，不会再请求一次 TTS。

**喇叭开关**：右下角 🔊 可开关语音，选择会记住（默认开启）。提示「权限等级不足」或未配置 API Key 时，喇叭自动转为不可用状态；其余流程不受影响。

**背景音乐（AI 自动作曲）**：首个场景的背景、立绘到位后，AI 会按当前氛围**自己创作一段 MIDI 背景音乐**，在你的浏览器里用 FluidSynth（GeneralUser GS 音色）本地合成、循环播放——服务端不产生任何音频开销。台词语音响起时 BGM 自动压低、台词结束自动恢复；场景发生较大变化时，AI 会先查看本会话已有曲目，能复用就直接换、没有才新作。右下角 🎵 可随时开关音乐（默认开启、选择会记住）。
首次播放需要下载约 32MB 的 GS 音色库（DEBUG 面板会显示进度），下载后会**持久化保存在浏览器本地**（站点存储，清理普通缓存不会删除），只此一次；浏览器不支持 WASM 或下载失败时静默降级为无音乐，不影响剧情与语音。

**资产复用**：同一个角色的立绘会绑定在角色卡上、**跨会话复用**；背景与背景音乐按会话存放。AI 想换造型/场景/音乐时会先查看已有资产，有合适的直接切换、没有合适的才重新生成或创作——不会每次都重画重写。

**长相一致性**：首张立绘以角色卡头像为参考；从第二张起，每次新立绘都必须引用至少一张历史立绘作为参考图（AI 会挑选装束 / 长相最接近的），即使模型忘了传也会自动补上当前画面上的立绘——多次换装、换表情后人物长相不会跑偏。初期还没有立绘时无此要求。

**音量调节**：左上角 ⚙ → 设置弹窗里有两根滑杆，分别调整 **🎵 背景音乐音量**与 **🔊 语音（TTS）音量**，拖动即时生效、选择会记住（默认均为 100）。BGM 采用原生无缝循环，结尾到重新开始之间没有停顿。

**对白回看（Backlog）**：点左上角 📜 按钮，或在画面上**鼠标滚轮向上滑**，即可调出全屏回看清单：按故事顺序列出所有台词（带角色名）、动作、叙述以及你的自由输入；**你每次选择的选项**会以「你的选择」行展示在对应剧情之后。若当时 600 秒内没有作答，会显示「⏱ 超时（600 秒未作答，剧情自行继续）」；工具异常会显示具体错误；尚未作答的最新选项才显示「等待选择…」。点某句台词可重听它已保存的语音（会像演出时一样压低 BGM）；点清单外的空白区域或按 Esc 返回当前位置。

**剧情重放**：回看清单顶部有「🔁 从头开始回放整个故事」，即使故事最初还没有选项也能完整回放；每个已作答的选择行、以及**超时未答的行**上也都有「🔁 从此处重放」按钮，点击后从该节点**之后的剧情**开始本地重放：逐句重新演出对白（打字机、语音、立绘 / 背景切换、BGM 与当初一致），遇到选择时**只给出当时选中的那一个选项**；遇到超时 / 工具异常节点则显示当时状态，点击即可越过，不会调用 AI、也不会改变已有剧情。重放期间画面顶部的提示条会挡住立绘：点提示条上的「—」可把它最小化成左下角的小 🔁 圆标，点圆标恢复；也可随时点「✕ 结束重放」退出。重放到最新一条后自动结束并回到当前位置。若当时有仍在进行的演出，结束重放时会自动重新接上。

**自动播放**：右下角 ▶ 按钮开启后（变为 ⏩），每句话演完会停顿约 1 秒自动进入下一句，不用一直点屏幕；如果语音还没播完，会等语音播完再走；整段结束、选项出现时会自动停下，选项始终需要手动选择。再次点击按钮关闭，选择会记住。

**存档点**：左上角 ⚙ → 设置弹窗里有「💾 存档点」区块——在名称框写好备注（可选）点「保存当前位置」，就把此刻的全部剧情与场景存为一个存档点；下方清单按时间列出所有存档点（场景缩略图、名称、时间、消息数），点「回到这里」即可从该存档点重新开始。回档前会弹窗确认：可选择「💾 保存当前并回档」（先把当前位置另存一个存档点，之后反悔也能找回）、「不保存，直接回档」或取消；回档后剧情会以存档点内容重建，BGM 自动停止、随后按新场景恢复。不再需要的存档点可点「删除」。每个会话最多保留 30 个存档点，超出后最旧的会自动淘汰。

**换设备继续玩**：故事运行在服务端，在另一台设备/另一个浏览器窗口登录同一账号、点进该会话时，会自动发现仍在进行的演出并接上事件流（包括正在等待的选项），直接继续即可；即使先做了操作也不会报「已有进行中的回答」，客户端会静默改为续读。

**返回主界面**：左上角 ⚙ → 设置弹窗里点「🏠 返回主界面」即可退出全屏、回到普通聊天界面。后台故事不会中断，再次点进该会话即可继续；万一刷新了页面，也会像普通聊天一样自动回放已生成的内容。

**提示**：生图走云端生图模型（需已配置可用模型；API Key 可留空）；绿幕抠像效果取决于模型出图，边缘偶有绿痕属正常现象。管理员可在「⚙️ 设置 → Galgame 模式」调整最大工具轮数（默认 40），剧情段落特别多时可调大。

**调试面板**：画面右上角有半透明 DEBUG 面板，实时显示当前状态（接收/工具/整段语音准备/回放/等待选择）、run 与序号、TTS 进度和最近事件；点击「DEBUG」标题或右侧 − 可折叠为只剩标题条，折叠时悬停标题可看当前状态，点 + 展开。

## 六、导出 / 导入

### 角色与世界

- 在「🧩 内容」列表里，每个角色/世界都有**导出**按钮 → 把卡片保存为 `.json` 文件，方便备份或分享。
- 列表顶部有**导入**按钮 → 选择 `.json` 文件即可载入（导入会生成新 ID，不覆盖现有卡片）。
- 导出文件内含该卡片的全部信息（含要求字段）。**注意**：头像引用的是本机路径，导入到另一台机器时头像可能不显示，可重新上传。

### 对话（含 Galgame 素材）

- 会话 / 房间菜单里点「⬇ 导出对话」→ 下载 **`.zip` 自包含迁移包**：除完整对话文本（含工具调用记录）外，还会把对话中引用到的**背景、立绘、MIDI 曲目、已合成 TTS 语音**全部打包，适合备份或迁移到另一台服务器 / 另一个账号。
- 侧栏会话列表顶部的**导入**按钮支持两种文件：
  - `.zip` 迁移包：素材自动释放到当前账号的上传目录，对话中的地址会**改写为当前账号地址**，直接可看可听；
  - 旧版 `.json` 纯文本包（仅文本，素材不带）。
- 导入始终生成**全新会话**（新 ID），不会覆盖任何现有会话；包内角色卡在本库已存在则复用库卡，不存在则降为会话专属副本，不会污染你的角色卡库。
- 如果只想迁移剧情、不想要旧语音（音色不同或想重新合成），可在导出接口加 `?include_tts=false`，包内不含语音文件且清空语音映射。

## 七、多用户（登录页 + 管理员）

- 打开即进入**独立登录页 `/login`**，手动输入用户名密码，验证通过才可进入主界面（不登录进不去）。左下角显示当前用户，「退出」立即吊销令牌、回到登录页。
- **登录令牌**：登录成功后服务端签发随机不透明令牌（有效期 7 天），浏览器存 localStorage，服务端同时持久化到 `data/auth_sessions.db`——**刷新页面、重启服务都不掉登录态**。之后所有数据请求都带 `Authorization: Bearer <令牌>`，仅凭用户名（包括 `X-User-Id: admin`）不再能访问任何接口。
- **登录限速**：同一 IP + 用户名连续 **5 次密码错误即锁定 5 分钟**，锁定期间即使密码正确也会被拒（HTTP 429）；用户不存在同样计入失败，无法据此试探用户名。
- **管理员与普通用户分开**：
  - **管理员**：账号凭据写在 `config/config.json` 的 `auth.admin`（`username` / `password`）。**没有自动创建的任何默认用户**，管理员是谁完全由你在这份配置里决定。建议设一个真实密码，并妥善保管。
  - **普通用户**：存在 `data/users.db`，**不能自助注册**，只能由管理员在侧栏「👥 用户管理」中创建；管理员也可在此修改等级、删除用户。
- **管理员重置用户密码**：「👥 用户管理」每个用户行点「🔑 改密」，行内输入新密码（留空表示无密码）确认即可。重置后**该用户的现有登录会话立即全部失效**，需用新密码重新登录。
- **对话次数计费（管理员）**：
  - **模型倍率**：在「⚙️ 设置 → 模型」给每个模型填「计费倍率」（默认 1.0，可填 0.5、1.5、2 等小数，0=免费）。普通用户每发一轮对话扣 `1 × 当前所用模型的倍率` 次；群聊按**实际发言的 AI 逐个累计**（每个座位用自己的模型倍率，回复「略」跳过的 AI 不计费）。重新生成、编辑后重发、Galgame 续接都按正常一轮计费；模型调用失败或被取消时，未实际发言的部分自动退回。
  - **发放/充值次数**：「👥 用户管理」创建用户时可填初始「对话次数」，之后在用户行的「总额」输入框随时调整（修改后即时生效，刷新页面即看到新余额）；填 **-1 表示不限次数**。次数允许小数，界面保留两位显示。
  - **管理员本人完全不受计费限制**，也看不到余额条。
- **对话次数（普通用户）**：输入框上方的「🎟 剩余 N 次对话」实时显示余额，每轮结束自动刷新。次数用完后发送消息会被拒绝并提示「对话次数已用完，请联系管理员充值」，余额不会被透支；被拒绝的消息不会写入历史，充值后直接重发即可。
- **不登录不能进入**：不提供有效令牌就无法进入主界面或访问任何数据接口。
- 数据（角色卡、世界观、会话、上传头像）**按用户完全隔离**（管理员与各普通用户各有独立目录）。
- 提供商、插件、全局工具设置是**所有用户共享**的（本地工具的一面）；功能类开关在共享默认值之外，允许每个用户单独覆盖（见下条）。
- **功能开关下放给用户（设置 → 功能开关）**：
  - 工具与迭代（工具总开关、最大迭代轮数、超时）、角色扮演（格式规范、属性跟踪、五段提示词字数预算）、联网搜索、AI 浏览器、P 站搜图、Galgame 模式（含单轮循环上限）、AI 生图，共 7 组，普通用户都可以**仅对自己**覆盖。
  - 每组默认勾选「**跟随全局默认**」：此时使用管理员的设置，控件只读显示当前全局值；管理员修改默认后，仍在跟随的用户自动跟着变化。取消勾选即可自定义，保存后立即对自己的新一轮对话生效；重新勾选并保存即恢复跟随。覆盖值保存在本人 `data/<用户名>/settings.db`，不影响其他用户，也不会改动全局配置。
  - Galgame 额外有房间创建门槛：全局关闭且用户未覆盖开启时，新建 Galgame 房间会被拒绝；用户可在自己的功能开关里单独打开。
  - 语音合成（TTS）不提供用户级开关，只按管理员的全局设置与最低等级生效。
- **共享模型只露必要信息**：普通用户对「管理员（或其他用户）共享」的模型，只能看到 **模型名/ID、是否支持视觉、计费倍率、所需最低等级**；接口不会下发 Base URL、API Key、归属人等任何敏感字段，界面上对应位置显示「== 暂不显示 ==」。**自己创建的模型不受影响**：仍可查看 Base URL 与掩码 Key、随时增删改；未达等级门槛的共享模型完全不可见、不可选用。
- 切换用户 / 删除用户都不会影响其他用户的数据。

## 八、常见问题

- **AI 不查询内容表？** → 检查会话顶栏是否已选角色/世界观；内容表条目标题是否够具体；工具是否在设置中启用。关键设定可直接勾「常驻」强制注入，不依赖 AI 主动查询。
- **AI 的语气不像角色？** → 在角色卡「对话范例」里给 3~5 轮带动作、口癖的 `<START>` 分隔范例，比在简介里写性格描述有效得多。
- **想用两张图配合改图（换装/换场景）？** → 按顺序发图并说明「第一张…第二张…」，AI 会把两张都作为参考（最多 14 张）；若它只参考了一张，明确要求「两张都要用，图1是人物、图2是服装」即可。
- **压缩后担心 AI 漏了设定？** → 内容表按标题合并，漏列的条目原样保留；且确认前可完整查看 diff，放弃即不写入。
- **AI 抓的网页太长，后面的内容看得到吗？** → 可以。web_fetch 分页返回（默认每次 6000 字），AI 需要后续内容时用相同 URL 加 `offset=6000`、`offset=12000` 继续读，直到页面末尾；翻页读的是服务端缓存，不会重复下载。
- **设置了预算后想恢复全量注入？** → 把对应预算改回 0 即可，0=不限。
- **回答到一半刷新页面，回答会丢吗？** → 不会。生成在后台任务中继续、事件带序号全量缓存：刷新后页面会自动回到原会话，先回放已生成内容、再实时显示后续直到回答结束。网络抖动断连也会自动重连（指数退避，最多 8 次，toast 有提示）。若服务进程重启，或距回答结束已超过 10 分钟（服务端缓存窗口），则无法续接。
- **点「停止」后已经写出的内容？** → 会作为半截回复保存在会话里，刷新后仍看得到，不会整段消失。
- **属性不动？** → 确认设置里已开启「属性跟踪」且在会话中选择了角色/世界观；提示词里说明了每回合结束更新。
- **历史刷新后工具卡片状态不对？** → 新版已把工具的成功/失败状态持久化进会话消息（`ok` 字段），旧会话按内容前缀智能推断。
- **提示「对话次数已用完」？** → 账号的计费次数已耗尽，联系管理员在「👥 用户管理」里把「总额」调高（-1 为不限次数）。模型报错、停止或群聊中 AI 回「略」跳过的部分都不会被扣费。
- **忘记某个用户密码？** → 让管理员在「👥 用户管理 → 🔑 改密」直接重置；也可以在 `data/users.db` 的 `users` 表里把该用户的 `password_hash` 清空，留空密码即视为任意输入可进。
- **忘记管理员密码？** → 直接编辑 `config/config.json` 的 `auth.admin.password`，改成一个你知道的即可（本地工具，重启后生效）。
- **登录提示“用户名或密码错误”？** → 新版不区分用户名是否存在（防止枚举）。管理员账号请用 `config` 中 `auth.admin` 设置的 `username`；普通用户需由管理员在「👥 用户管理」中创建。
- **登录提示“登录失败次数过多，请 N 秒后再试”？** → 该 IP + 用户名连续 5 次失败已被锁定，等倒计时结束再试。
- **手机上按 Enter 没法换行、直接发出去了？** → 打开「⚙️ 设置 → 偏好」，取消勾选「Enter 键发送消息」：之后 Enter 正常换行，发送点发送按钮（或用 Ctrl+Enter）。FlyAI 会自动识别手机端（含 iPadOS 伪装成桌面 UA 的情况），手机上首次使用默认就是关闭的；桌面端默认开启，可随时改，偏好保存在本浏览器。
