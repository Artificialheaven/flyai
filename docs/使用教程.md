# FlyAI 使用教程

本文从零开始，帮你快速上手，并重点讲解**如何写出完善的角色卡与世界观**，让 AI 的扮演质量明显提升。

---

## 一、快速开始

1. **启动**
   ```bash
   .venv\Scripts\python main.py
   ```
   浏览器打开 <http://127.0.0.1:8000>。

2. **登录用户**
   打开工具会进入**独立登录页**（`/login`），**不登录无法进入**。用管理员或普通用户账号登录后进入主界面（密码可留空）。角色卡、世界观、会话都**按用户隔离**，不同用户名之间互不干扰；左下角「退出」随时可回到登录页切换。**管理员账号与密码在 `config/config.json` 的 `auth.admin` 中设置**（首次默认 `admin` / 空密码，建议改掉）；**普通用户需由管理员在「用户管理」中创建**，不能自助注册（详见「多用户」一节）。

3. **配置 AI 提供商**
   点左侧「⚙️ 设置」→「提供商」→「＋ 新增提供商」，填入：
   - **ID**：任意唯一名（如 `deepseek`）
   - **类型**：`openai`（OpenAI 兼容，含 DeepSeek/Kimi/Qwen 等）或 `anthropic`
   - **Base URL**：如 `https://api.deepseek.com/v1`
   - **API Key**、**模型名**（如 `deepseek-chat`）
   - 勾选设为**激活**，点「保存」。

4. **新建会话**：点侧栏「＋」。然后就可以在底部输入框和 AI 对话了。

> `config/config.json` 里保存的是真实配置（含 API Key），不会入库；仓库只保留 `config.example.json`。

## 二、理解核心概念

| 概念 | 作用 |
|---|---|
| **会话** | 一段对话历史，可单独绑定一个角色 + 一个世界观 |
| **角色卡** | 你要扮演的那个角色：人设、经历、内容表 |
| **世界观** | 整个故事的设定：世界是什么样、有什么规则 |
| **内容表** | 角色卡/世界观各自附带的一张「标题→内容」资料库，AI 通过工具按需查询 |
| **属性跟踪** | 好感度、金钱这类会随剧情变化的值，AI 每回合可调用工具修改 |
| **对话格式** | 动作 / 内心活动 / 对白的书写规范，前端会分区着色显示 |

**最关键的一条**：会话顶栏有「角色」「世界观」两个下拉框。**选好角色与世界观后**，它们的人设、设定、内容表、要求才会注入这一次对话。

## 三、如何写出完善的角色卡

点左侧「🧩 内容」→「＋ 新建角色」。每个字段怎么填，直接决定扮演水平：

### 1. 角色名称
清晰、唯一的名字。建议同时给一个称号化名会更有质感，例如「爱丽丝 · 雾都旅者」。

### 2. 头像（可选）
点击头像框上传一张图片，会让界面更直观，不影响 AI 质量。

### 3. 【角色简介】——最重要的字段
一句话到一小段，说清这个角色**是谁、给人的第一印象、说话风格**。它决定了 AI 的基础人设。

> ❌ 差：「爱丽丝，女，二十岁。」
> ✅ 好：「一位冷静、毒舌却心地善良的年轻旅者，习惯用刻薄的玩笑掩饰受伤，面对陌生人的第一句话往往是嘲讽，但从不真的拒绝帮助他人。」

要点：
- **性格**（不只说职业/身份，说性格特质）
- **说话风格**（口头禅、语气、用词习惯）
- **态度倾向**（对主角是亲近、戒备还是疏远，可随剧情变化）
- **一个记忆锚点**（比如一个不愿提起的过去），让 AI 有东西可以深化

### 4. 【角色经历】——给角色的"过去"
写 2–6 段重要过往。它让 AI 的言行有来源，而不是凭空。建议包含：
- 出身与转折点（一次事件如何改变了她）
- 与主角（或这个世界）的既有关系
- 未解的心结或目标（让剧情有方向）

> 「出身海雾港的孤儿，十五岁那次遇难事件后患上惧水症，却故作洒脱地四处旅行，试图找到一个‘不必回头’的理由。与你说好同行一段路，实则在悄悄试探你是否可靠。」

### 5. 【内容表】——AI 可按需查询的资料库
这是本工具的特色。内容表的每条 = **一个标题 + 一段内容**。AI 随时可用 `query_lore` 工具按标题模糊查询。

**怎么用最有效：**
- 把**会变化的细分设定**放进内容表，而不是塞进简介/经历，避免每次注入导致上下文膨胀。
- 标题要短而清晰，让 AI 能猜到关键词：`家庭`、`能力图谱`、`暗号`、`对主角的评价`、`关键事件真相`。

**示例：**
| 标题 | 内容 |
|---|---|
| 家庭 | 烟枪叶家族，父母双亡，与弟弟艾伦相依为命 |
| 能力图谱 | 愈合之瞳（上限）、雾语术（进攻）、探知（辅助） |
| 对主角的评价 | 起初戒备，发现对方守诺后逐步信任 |
| 未解之谜 | 母亲留下的半张地图，指向雾都地下的古港 |

> 技巧：内容写得越具体，AI 查出来用上的质量越高。避免「她很强」这种，改成「她的雾语术可将 20 米内的声响折叠，某次为保护队友连续使用导致脱力」。

### 6. 【对白格式要求】/【工具使用要求】
这两个文本框会**自动填入内置默认**。你可以为这个角色单独改写，比如强调她的口癖、不许用某类句式的规定等。留空则遵循全局默认。

## 四、如何写出完善的世界观

点「🧩 内容」→「＋ 新建世界观」。世界观提供的是**整场故事的规则与舞台**。

### 1. 【世界观内容】——世界的骨架
写清楚以下内容（不必长篇，重在有信息量）：
- **基础设定**：时间/地点/整体氛围或核心设定
- **运行规则**：这个世界最特殊的规则（魔法体系、科技水平、禁忌）
- **势力格局**：主要势力、阵营、矛盾
- **主角所处位置**：主角从哪出发、目标是什么

> 「雾都 · 利默，终年笼着能吞噬声响的灰雾。这里没有标准货币，一切交易以‘记忆’为筹码——每付一次价，就失去一段记忆碎片。铁匠行会垄断了记忆提炼术，城外的雾隐教视为亵渎。你是一个失去全部记忆的旅人，唯一线索是左臂上那枚雾色的印记。」

### 2. 【内容表】——世界的"细节词典"
和角色内容表一样，按标题组织，AI 按需查询。放**需要时才出现的具体设定**。

**示例：**
| 标题 | 内容 |
|---|---|
| 记忆货币 | 一枚记忆币 = 约三天的普通记忆；高价值记忆可铸成彩色币 |
| 雾隐教 | 相信记忆是灵魂的一部分，主张归还，与铁匠行会对立 |
| 灰雾 | 每小时随钟声涨落一次，雾中人会遗忘新近 10 分钟言行 |
| 关键地点 | 旧钟塔、记忆交易所、雾台 |

## 五、让扮演质量更高的小技巧

### 1. 分层"注入"而不是"倾倒"
- **永远在线的**：简介 + 经历（每次对话都注入）→ 写最核心、最常用的人设。
- **按需查询的**：内容表（AI 需要才调 `query_lore`）→ 写分支细节、可变化设定。
- 这样上下文更省 token，AI 也更有"主动翻资料"的能力。

### 2. 驱动工具使用
- 提示词中已教会 AI 在需要细节时调用 `query_lore`。当内容表足够有料时，AI 会主动查询，而不是瞎编。
- 设置 → 工具里可调「最大工具迭代轮数」（默认 8）、文件读取白名单目录。
- 工具栏执行会以**绿/红卡片**展示成功/失败状态；失败时 AI 会收到失败信息并自行纠错。

### 3. 对话格式与分区显示
默认开启「对白格式规范」：动作用 `（ ）`、内心活动用 `____…____`、对白用 `「」`，空行分段。前端会把**对白（蓝）、动作（斜体灰）、内心（斜体黄）**区分显示，阅读体验更接近小说。
可在「设置 → 角色扮演」里开关，或为单个角色单独改写。

### 4. 属性跟踪
设置里可启用「属性跟踪」。默认定义了好感度、金钱。开启后 AI 会在**每回合结束**调用 `update_attributes` 增减这些值，顶栏实时显示。
- **由 AI 自行提供**：AI 自己根据剧情判断好感度怎么变。
- 关闭自动提供：AI 仅在剧情需要时调整。
- 也可以自己改 `config/config.json` 的 `roleplay.attributes.list` 增删属性及其范围。

### 5. 会话绑定
同一个角色可以配不同世界观产生不同故事；同一世界观也能配不同角色。会话顶栏随时切换。

## 六、导出 / 导入角色与世界

- 在「🧩 内容」列表里，每个角色/世界都有**导出**按钮 → 把卡片保存为 `.json` 文件，方便备份或分享。
- 列表顶部有**导入**按钮 → 选择 `.json` 文件即可载入（导入会生成新 ID，不覆盖现有卡片）。
- 导出文件内含该卡片的全部信息（含要求字段）。**注意**：头像引用的是本机路径，导入到另一台机器时头像可能不显示，可重新上传。

## 七、多用户（登录页 + 管理员）

- 打开即进入**独立登录页 `/login`**，验证通过才可进入主界面（不登录进不去）。左下角显示当前用户，「退出」回到登录页切换。
- **管理员与普通用户分开**：
  - **管理员**：账号凭据写在 `config/config.json` 的 `auth.admin`（`username` / `password`）。**没有自动创建的任何默认用户**，管理员是谁完全由你在这份配置里决定。建议设一个真实密码，并妥善保管。
  - **普通用户**：存在 `data/users.json`，**不能自助注册**，只能由管理员在侧栏「👥 用户管理」中创建；管理员也可在此删除普通用户。
- **不登录不能进入**：不提供有效账号就无法进入主界面或访问任何数据接口。
- 数据（角色卡、世界观、会话、上传头像）**按用户完全隔离**（管理员与各普通用户各有独立目录）。
- 提供商、插件、全局工具设置是**所有用户共享**的（本地工具的一面）。
- 切换用户 / 删除用户都不会影响其他用户的数据。

## 八、常见问题

- **AI 不查询内容表？** → 检查会话顶栏是否已选角色/世界观；内容表条目标题是否够具体；工具是否在设置中启用。
- **属性不动？** → 确认设置里已开启「属性跟踪」且在会话中选择了角色/世界观；提示词里说明了每回合结束更新。
- **历史刷新后工具卡片状态不对？** → 新版已把工具的成功/失败状态持久化进会话消息（`ok` 字段），旧会话按内容前缀智能推断。
- **忘记某个用户密码？** → 这是本地工具，直接在 `data/users.json` 里把该用户的 `password_hash` 清空即可（保留 `"password_hash": ""`），下一个用户留空密码即视为任意输入可进（或找管理员重建）。
- **忘记管理员密码？** → 直接编辑 `config/config.json` 的 `auth.admin.password`，改成一个你知道的即可（本地工具，重启后生效）。
- **登录提示“用户不存在”？** → 管理员账号请用 `config` 中 `auth.admin` 设置的 `username`；普通用户需由管理员在「👥 用户管理」中创建，不支持登录时自动注册。
