## 1. 本轮完成

### 1.1 带宽 / 存储（后端）

| 改动 | 位置 | 效果 |
|---|---|---|
| 单 AI 会话只落一份 override | `flyai/sessions/json_store.py` (`session_to_dict` / `session_from_dict`) | 顶层 `character_override` 与唯一 AI 座位副本相等时不再写入；读时指向同一对象 |
| `extensions.regex_scripts` 去重 | 同上 (`_dedupe_card_dict` / `_restore_card_dict`) | 与顶层 `regex_scripts` 相等时剥离约 0.9MB/卡，读时补回 |
| 会话文件指纹 | `SessionStore.stat` + `JsonSessionStore.stat` | 提供 `mtime_ns/size` |
| `GET /api/sessions/{sid}` 条件请求 | `flyai/api/routes_session.py:get_session` | 命中 `If-None-Match` 返回 **304**，稳态打开 0 字节 body |

实测三张测试卡（`show/*.png`）落盘体积：

| 卡 | PNG | 原会话 JSON（估算） | 本方案后 | 重建校验 |
|---|---|---|---|---|
| 滨莲市2.0 | 2.5MB | ~5.0MB | **0.5MB** | ✅ 62 世界书条目、9 正则 |
| 约会大作战P-v1 | 23.1MB | ~34MB | **3.6MB** | ✅ 220 条目、24 正则 |
| 我的存精罐，你的存钱罐 | 1.8MB | ~3.5MB | **0.5MB** | ✅ 16 条目、5 正则 |

> 约会卡 3.6MB 已优于方案里 11.6MB 的示例值，主要来自单份 override + regex 去重 + 既有 `tavern_helper` 剥离。

### 1.2 客户端缓存 / 重试 / 真实进度

- `services/flyai/sessions.ts`：新增 `getSessionConditional()`，按会话记录 ETag；304 返回 `null`，调用方保留本地状态；`invalidateSessionCache()` 供删除/切分支后强制全量。
- `services/chat/store.ts:refreshSession`：非 force 刷新改走条件请求，会话未变化时不再下载/解析大 JSON。
- `services/flyai/client.ts`：
  - `request()` 对 GET/HEAD 自动重试 3 次（网络错误、429/502/503/504，指数退避）；
  - 新增 `requestWithProgress()`：XHR 上传字节进度 + 自动重试（写请求显式开启）。
- `services/flyai/st.ts:writeSessionWorld`：改用 `requestWithProgress`，`retries=3`。
- `services/st/cardActivity.ts` + `components/base/CardSyncBar.tsx`：进度条支持真实上传百分比（0–100），重试时显示「重试 n/3」，无字节进度时仍按时长兜底。
- `components/markdown/CardAppFrame.tsx`：世界书写回接入真实进度回调。
