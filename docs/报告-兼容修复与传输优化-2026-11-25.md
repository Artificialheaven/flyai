## 2. 会话传输与带宽

### 2.1 响应去重（新客户端）

- 客户端请求带 `X-FlyAI-Client: 2`（`getSession` / 条件请求）
- 服务端 `GET /api/sessions/{sid}`：
  - 单 AI 会话：`members[].override = null` + `override_stub {name, avatar}`
  - `st.author.scripts` 不再内联，返回 `scripts_digest` + `scripts_url`
- 实测约会大作战：作者脚本约 5MB，首次之后由浏览器 `immutable` 缓存命中

### 2.2 卡包按 digest 下发

- 新增 `GET /api/sessions/{sid}/card-bundle?digest=`
  - 返回 `{digest, author_scripts, truncated}`
  - `ETag` + `Cache-Control: private, max-age=31536000, immutable`
- 客户端 `hydrateCardBundle()`：按 digest 缓存到内存，页面会话内不重复拉取

### 2.3 已有优化（本轮未改动，仍生效）

- 会话落盘：单 AI override 只存一份、regex 去重
- ETag/304 条件请求 + GET 重试
- 内容库头像 256px WebP 缩略图
- GZip 跳过 SSE/二进制

仍缺：增量消息 `sync`、`messages` 分页、图片外置、IndexedDB 按消息落盘。

## 4. DeepSeek 开放平台（管理员）

### 4.1 登录与 Key 写入

- 设置 → 用量 → 「DeepSeek 开放平台」（仅管理员可见）：
  - 「登录开放平台」打开 `platform.deepseek.com/sign_in`
  - 登录返回后自动打开 API Keys 页（浏览器拦截时给出手动链接）
  - 粘贴 Key → 后端用 `GET https://api.deepseek.com/user/balance` 校验
  - 通过后自动创建/更新模型列表中的 `deepseek-official` provider（`https://api.deepseek.com`，
    `deepseek-chat`/`deepseek-reasoner` 可选）并激活
- **限制说明**：DeepSeek 官方没有 OAuth，也没有“创建 API Key”的公开接口；
  因此无法自动生成 Key，只能登录后在平台创建并粘贴。前端已明确提示。
- Key 只写不读：所有接口仅返回掩码（`sk-a****5678`）。

### 4.2 官方额度与 token

- 使用模型为 DeepSeek 官方（base_url 含 `api.deepseek.com` 且为当前激活 provider）时：
  - 用量页主额度卡替换为 **官方余额**（`is_available` + `balance_infos` 多币种）
  - 提供「前往充值」「官方用量页」入口
- token 统计：官方 API **没有用量查询接口**，下方 token 仍为本地统计，
  页面明确标注并链接官方用量页对照；点击刷新会同时刷新余额与本地统计。
