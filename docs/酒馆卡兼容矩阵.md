# 酒馆卡（SillyTavern）兼容矩阵

FlyAI 原生支持酒馆角色卡中**声明式**的扩展特性。核心边界：

> **默认绝不执行角色卡自带的任何 JavaScript**（tavern_helper 的 CDN import、
> MVU bundle、Zod schema 脚本等一律只作为数据保存），也不发起卡内声明的
> 任何网络请求。所有变量更新与展示效果都由 FlyAI 原生代码重新实现。
>
> 唯一的例外是**显式开启的脚本沙箱**（`st_js_sandbox_enabled`）：卡内整页
> HTML+JS 应用会被放进**无同源权限的 null-origin iframe** 运行，只能读当前
> 消息文本、不能访问 localStorage/Cookie/bearer token、不能联网（仅放行白名单
> CDN 静态资源）。tavern_helper、MVU bundle 等仍不执行。详见第四节。

## 一、能力总览

| 特性 | 支持方式 | 默认 | 说明 |
|---|---|---|---|
| `regex_scripts` | 原生正则引擎（后端 prompt 侧 + 前端展示侧） | 开 | 卡内脚本 0/1/3/4/5 这类声明式替换可生效 |
| MVU 变量系统 | 原生 InitVar / RFC 6902 / 宏 | 开 | 不执行 MVU bundle，语义由 `flyai/st/mvu.py` 实现 |
| `depth_prompt` | 作为深度注入条目追加 | 开 | 支持 `{{char}}`/`{{user}}` 等宏 |
| 消息内 HTML | DOMPurify 白名单清洗后渲染 | 开 | `<details>`/`<table>` 状态面板可显示 |
| 整页 HTML+JS 应用 | null-origin 沙箱 iframe | 关 | 每用户开关 `st_js_sandbox_enabled`；管理员默认开、普通用户默认关 |
| 状态面板 | 独立抽屉/全屏页 + 按消息快照回看 | 开 | 卡内模板缺失时以 `stat_data` 键值兜底 |
| 内联插图 | Markdown/HTML `<img>` + 全屏看图器 | 开（站内图） | 外链图片默认不加载，见下 |
| 外链图片（方案 1） | 浏览器直连，`referrerpolicy=no-referrer` | 关 | 每用户开关 `st_external_images_enabled` |
| 外链图片（方案 4） | `/api/st/img-proxy` 服务端代理 | 关 | 需管理员开启 + 权限等级达标 |
| `alternate_greetings` | 原样保留；单角色新建房间时可选择 | — | 见第六节已知偏差 |
| `assets` | 保留元数据 | — | 暂未同步到 FlyAI 资源库 |
| `extensions`（world/talkativeness/fav 等） | 原样保留 | — | `world` 不自动关联，导入报告会提示 |
| `tavern_helper` | 仅保存，不执行 | — | 导入报告明确提示 |

## 二、正则脚本（regex_scripts）

- 位置：`findRegex` 支持裸模式字符串与 `/pattern/flags` 字面量；`g/s/i/m/y`
  标志按各自语义映射（`y` 在 Python 侧忽略）。
- 生效位置：`placement` 1 = 用户消息，2 = AI 消息，可同时包含；缺省为 AI 消息。
- 侧别：`markdownOnly` 只在展示侧执行，`promptOnly` 只在出站 prompt 侧执行，
  两者都不设则两侧都执行；`disabled` 跳过。
- 深度过滤：`minDepth`/`maxDepth`（0 或负数表示无限制）。
- 替换串：支持 `$1`…`$99`、`$&`、`$``、`$'`、`$$`、`$<name>`；`trimStrings`
  会从捕获组结果中剔除指定子串。
- 容错：单条脚本正则无效时**只跳过该条并计入导入报告**，不影响其它脚本
  （卡内脚本 2 本身就是语法错误）。
- 限额：脚本数 ≤ 200、单 pattern ≤ 64KB、单次输出 ≤ 2MB，超限跳过。

**展示侧与存储原文分离**：展示侧正则只影响消息的渲染结果。复制、朗读、导出
仍使用模型返回的原始文本，因此不会把状态面板的 HTML 或美化结果带出去。

## 三、MVU 变量系统

- **InitVar**：从角色卡内容表中标题含 `[InitVar]` 的条目提取 YAML（支持多段
  code fence 深合并，单段上限 256KB），得到初始 `stat_data`。Zod 脚本里的默认值
  不执行，缺失字段以 InitVar 为准。
- **更新解析**：从助手消息提取 `<UpdateVariable>…<JSONPatch>…</JSONPatch>
  </UpdateVariable>`（大小写不敏感，兼容多个更新块），原生实现 RFC 6902 的
  `add/remove/replace/move/copy/test`，支持 `~0`/`~1` 转义与 `-` 追加。
- **原子应用**：一个更新块内任一操作失败则整块丢弃并记录 warning，不会半更新。
- **路径归一化**：`/stat_data/x`、`/x`、`stat_data.x` 都落到 `stat_data` 根。
- **宏**：`{{format_message_variable::stat_data.<path>}}` 在展示侧与出站 prompt
  侧展开；数组下标写作 `stat_data.物品[1]`；缺失字段展开为空串。
- **快照与回退**：每条助手消息保存生成后的 `stat_data` 快照；编辑、重生成、
  切换变体、删除消息、会话加载时，以「最后一条可见助手消息的快照」重算当前
  状态。
- **prompt 侧兜底**：发给模型的副本会剥离 `<UpdateVariable>` 块；存储原文保留，
  供卡内展示正则（如脚本 3/4）美化渲染。
- **兜底展示**：卡内没有对应展示脚本时，消息里的 `<UpdateVariable>` 块不会以
  原文出现，而是被纯文本剥离。

## 四、HTML 与图片

### 白名单渲染

消息内 HTML 经 DOMPurify 清洗后渲染（单段 ≤ 256KB，超限降级为纯文本）：

- 允许：`details/summary/div/span/table/thead/tbody/tfoot/tr/th/td/caption/
  colgroup/col/ul/ol/li/p/b/i/em/strong/u/s/del/ins/small/sub/sup/mark/abbr/
  kbd/samp/var/br/hr/center/img/a/code/pre/blockquote/h1-h6`
- 禁止：`script/style/iframe/object/embed/svg/math/form/input/link/meta` 等。
- 属性：`img` 仅 `src/alt/title/width/height/loading/referrerpolicy`；
  `a` 仅 `href/title`，且统一加 `target="_blank" rel="noopener noreferrer"`。
- `style` 走属性白名单（禁 `position/fixed/z-index/url()/expression/behavior/
  var()`，值长度 ≤ 300）；`class` 仅保留 `safe-*` 前缀。
- 链接协议：`http/https/mailto`、站内相对路径、页内锚点；拒绝
  `javascript:`/`data:`/`vbscript:` 与控制字符。
- 图片协议：站内相对路径与同源地址始终允许；外链需开启对应开关；
  `data:`/`blob:`/`javascript:` 始终拒绝。
- **空槽位剪枝**：卡内脚本常在 `data-name` 为空或占位值（`暂无`/`无`/`null`/
  `undefined`）时隐藏对应块。FlyAI 不执行卡内 JavaScript，改为在清洗前对这类
  `[data-name]` 元素做等价的原生剪枝（惰性 `<template>` 解析，不触发脚本）。

### 整页 HTML+JS 应用（脚本沙箱）

卡内通过正则替换生成的**整页 HTML 文档**（含 `<script>`）在开启
`st_js_sandbox_enabled` 后，会被放进沙箱 iframe 运行，而不是当代码块显示：

- **触发条件**：展示侧正则替换结果是完整文档（`<!DOCTYPE html>`/`<html>`）且带
  脚本、单段 ≤ 512KB；以 `$1` 等捕获组注入当前消息文本的卡（如希尔）可直接复现。
- **隔离**：`sandbox="allow-scripts allow-popups allow-popups-to-escape-sandbox"`，
  不含 `allow-same-origin`，因此 iframe 是 null origin，读不到宿主的
  localStorage/Cookie/DOM，也拿不到登录 token。
- **CSP**：`default-src 'none'`、`connect-src 'none'`、`frame-src 'none'`、
  `worker-src 'none'`、`object-src 'none'`、`base-uri 'none'`、
  `form-action 'none'`；仅放行 `cdn.tailwindcss.com`、`code.jquery.com`、
  `cdn.jsdelivr.net`、`cdnjs.cloudflare.com`、`unpkg.com` 的脚本/样式/字体。
- **媒体**：`img-src`/`media-src` 默认只允许 `data:`/`blob:`；开启
  `st_external_images_enabled` 后追加 `https:`（复用外链图片开关）。
- **shim**：注入轻量兼容层，支持 `getChatMessages`（仅返回**当前这条消息**）、
  `getCurrentMessageId`/`getLastMessageId`、`getVariables`（恒为 `{}`）、
  `triggerSlash`（空操作）、`toastr`、`SillyTavern.getContext`、`TavernHelper`
  别名；`localStorage`/`sessionStorage` 为内存实现，刷新即失。
- **交互**：iframe 内点击 http(s) 链接会经 `window.open(..., 'noopener')` 在
  新标签打开；高度通过 `postMessage` 自动同步，工具栏提供重新加载/全屏。
- **不支持的卡内能力**：变量系统（`getVariables` 恒为 `{}`，未提供
  `setVariables`）、任意网络请求（`fetch`/`XHR` 被 CSP 拒绝）、跨消息读取、
  `triggerSlash` 指令（空操作）。

### 外链图片策略

- **方案 1（默认实现，需用户开启）**：浏览器直连外链图片，带
  `loading="lazy" referrerpolicy="no-referrer"`。
- **方案 4（可选，服务端代理）**：`GET /api/st/img-proxy?url=…`。
  - 仅在 `config.st_image.enabled=true` 且用户权限等级 ≥
    `config.st_image.min_level`（默认 256，即仅 admin）时可用；
  - 还需用户开启 `st_image_proxy_enabled`；
  - 域名白名单 `allowed_domains`（空 = 不限域名，但仍拦截内网地址）；
  - 复用 netguard 的 DNS/IP 校验并逐跳校验重定向，钉住连接 IP；
  - 只接受 `image/png|jpeg|gif|webp|avif`，上限 8MB；
  - 响应带 `nosniff`、`no-referrer`、`default-src 'none'; sandbox` 等头。

### 状态面板查看

卡内「占位符 → HTML 面板」的展示脚本（如脚本 1）会被识别为面板模板，
在会话顶栏（桌面端标题栏 / 移动端顶栏）提供入口：

- **抽屉 / 全屏**：桌面端右侧滑出，移动端底部弹出，可切换全屏；支持系统返回键关闭。
- **快照回看**：选择器列出每条带 `stat_data` 快照的助手回复（最新在前），
  可回看历史状态；「当前状态」跟随会话级变量。
- **自动追加（可选，默认关）**：开启后在每条助手回复下方追加**该消息自身快照**
  渲染的面板；偏好存本机 `localStorage`。
- **原生兜底**：卡内没有可渲染的面板模板（或 HTML 渲染关闭）时，改为显示
  `stat_data` 的扁平键值行（对象递归成点路径，标量数组用「、」连接，最多 200 行）。

## 五、开关

| 键 | 作用域 | 默认 | 说明 |
|---|---|---|---|
| `st_regex_prompt_enabled` | 用户/全局 | 开 | 出站 prompt 侧正则 |
| `st_regex_display_enabled` | 用户/全局 | 开 | 展示侧正则 |
| `st_html_enabled` | 用户/全局 | 开 | 消息内 HTML 白名单渲染 |
| `st_js_sandbox_enabled` | 用户/全局 | 管理员开/普通用户关 | 整页 HTML+JS 应用在沙箱 iframe 中运行 |
| `st_external_images_enabled` | 用户/全局 | 关 | 直连外链图片 |
| `st_image_proxy_enabled` | 用户/全局 | 关 | 使用服务端图片代理 |
| `mvu_enabled` | 用户/全局 | 开 | MVU 变量系统 |
| `config.st_image.enabled` | 服务端 | 关 | 图片代理总开关 |
| `config.mvu.enabled` | 服务端 | 开 | MVU 总开关 |

关闭任一开关后，对应特性逐项降级为旧行为（HTML 转义显示、正则不生效、
`<UpdateVariable>` 纯文本剥离、外链图显示为替代文本）。关闭脚本沙箱后，整页
HTML+JS 应用回退为白名单清洗后的静态 HTML；HTML 渲染也关闭时显示为代码块。

## 六、已知偏差

1. **群聊只跟踪第一张 MVU 卡**：房间内多张卡都带 MVU 时，只启用首个命中卡片的
   变量状态，其余卡不维护独立状态。
2. **展示侧正则不影响复制/朗读/导出**：这三处始终使用模型返回的原始文本。
3. **Python `re` 与 JS RegExp 存在语法差异**：`\p{…}` 等 JS 专有语法无法编译，
   该脚本会被跳过并在导入报告中提示；命名分组已自动翻译。
4. **`alternate_greetings` 仅在单角色普通房间可选**：建房间时可在
   `first_mes` 与备选开场白之间挑一条；多角色房间与 Galgame 不播种开场白，
   因此没有选择入口。编辑器可增删改备选开场白。
5. **`assets` 未同步**：表情/背景资源只保留元数据，不会下载或注册到资源库。
6. **`world` 不自动关联**：卡内关联的世界书名称只写进导入报告，不做名称匹配
   或自动挂载；卡内嵌世界书条目仍会转换到内容表。
7. **`tavern_helper` 永不执行**：其中的脚本、CDN import、事件钩子都只是数据。
8. **MVU 更新为原子事务**：卡内若有“先改 A 再改 B”的多块更新，某块失败时该块
   整体丢弃，不会出现半更新状态。
9. **沙箱应用只读当前消息**：`getChatMessages` 只返回当前这条消息，依赖历史
   消息或变量系统（MVU/`getVariables`）的卡内应用无法完整复现；存储为内存实现，
   刷新即失。只读变量桥的设计草案见
   [`卡内只读数据桥方案.md`](./卡内只读数据桥方案.md)（未实施）。
10. **头像内嵌仅限 FlyAI JSON 导出**：导出文件带 `data.avatar_image`
    （PNG/JPEG/GIF/WebP 的 base64，上限 8MB）。导入时校验 MIME、base64 与文件
    魔数，失败则忽略图片但**不失败导入**（不会留下指向导出者目录的坏 URL）。
    `assets`（表情/背景）仍只保留元数据，不随 JSON 内嵌。
