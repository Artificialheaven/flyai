# 酒馆助手语义差异清单

检查时间：2026-11-23  
上游：`N0VI028/JS-Slash-Runner` 4.12.2  
本地：`webapp/src/services/st/authorRuntime.ts`  
验证方式：静态对比 `@types/function/*.d.ts` + 在《红楼风月录》作者 iframe 内实际调用

## 已实测确认的差异

### 1. 世界书 API 返回对象而不是数组（高影响）

- **上游**：`getWorldbook(name)` 返回 `WorldbookEntry[]`；`updateWorldbookWith(name, updater)` 把数组传给 updater，updater 返回数组。
- **本地**：`getWorldbook` 返回 `{ entries: {...} }` 对象；`updateWorldbookWith` 把同样的对象传给 updater。
- **实测**：`getWorldbookType = object`，`viaUpdate = false`（updater 收到的不是数组）。
- **影响**：
  - 《红楼风月录》时线调度器 `for (const entry of allEntries)` 直接失败，`buildTimeline()` 捕获后返回空数组，原著时线永远为空。
  - 《约会大作战》用 `Array.isArray(book)` 判断能力，返回对象时判定“世界书能力不可用”，相关功能降级。

### 2. `getChatMessages` 不支持范围和筛选（高影响）

- **上游**：`getChatMessages('0-10', {role:'user'})` 返回区间内所有楼层，支持负数深度、`{{lastMessageId}}`、`role`、`hide_state`、`include_swipes`。
- **本地**：只接受单个 id 或 id 数组，第二个参数被忽略。
- **实测**：`getChatMessages('0-10', {role:'user'})` 只返回最后一条消息（`rangeLen = 1`）。
- **影响**：《红楼风月录》的 `getChatMessages('0-10', { role: 'user' })` 读不到预期的用户楼层，修复开场玩家资料的逻辑失效。

### 3. `injectPrompts` 返回值不对，`filter` 丢失（高影响）

- **上游**：返回 `{ uninject() }`；`filter` 在每次生成时求值。
- **本地**：返回 `Promise`，没有 `uninject`；prompt 经 JSON clone 后 `filter` 函数被丢弃。
- **实测**：`injectRetType = object`，`hasUninject = false`。
- **影响**：
  - 卡里 `const { uninject } = injectPrompts(...)` 会得到 `undefined`。
  - 条件注入变成无条件注入；角色死亡/非活动状态下约束仍然存在。

### 4. 事件 API 返回值与常量值不一致（中高影响）

- `eventOn` / `eventOnce` / `eventMakeFirst` / `eventMakeLast` 上游返回 `{ stop() }`，本地返回 `undefined`。实测 `hasStop = false`。
- `eventEmit` 上游返回 `Promise<void>`，本地同步返回 `undefined`。
- `tavern_events.GENERATION_AFTER_COMMANDS` 上游值是 `'GENERATION_AFTER_COMMANDS'`，本地是 `'generation_after_commands'`。
- `iframe_events` 上游值是 `js_generation_requested` / `js_generation_started` / `js_generation_ended`，本地是 `iframe_generation_*`；缺两个流式事件。
- 缺 `eventOnButton`、`eventEmitAndWait`、`eventClearEvent`、`eventClearListener`、`eventClearAll`。
- 影响：依赖 `{stop}` 清理监听的脚本会报错；按上游字符串字面量注册/发送的事件对不上。

### 5. 变量作用域不完整（中影响）

- **上游**：`getVariables({type})` 支持 `chat` / `global` / `preset` / `character` / `message` / `script` / `extension`。
- **本地**：只区分 `message` 和其余（一律当聊天变量）。
- **实测**：`getVariables({type:'global'})` 返回的键与 `getVariables({type:'chat'})` 完全相同。
- `getGlobalVariables()` 永远返回 `{}`；`setGlobalVariable()` 永远返回 `false`。
- `deleteVariable(path)` 上游按 `a.b.c` 路径删除并返回 `{variables, delete_occurred}`；本地只删顶层键，返回变量表本身。
- 影响：使用全局变量做跨聊天设置、或按路径删除嵌套变量的卡会失效。

### 6. `context.generate(type, options)` 语义不同（中高影响）

- **上游**：`context.generate('normal', {quiet_prompt, ...})` 触发一次主聊天生成，回复会进入聊天楼层并派发 `MESSAGE_RECEIVED`。
- **本地**：`context.generate` 映射到静默生成桥，只在宿主弹确认并返回文本，不写入聊天、不产生新楼层。
- **影响**：《约会大作战》调用后等待聊天新增回复，本地会导致“本轮没有生成回复”或状态不同步。

### 7. 角色读取是简化版（中影响）

- `getCharacter()` 只返回 `{name, description, avatar}` 的克隆，缺少上游的 `first_messages`、`extensions`、`worldbook`、`creator_notes` 等。
- `getCurrentCharacterId()` 返回 `avatar || name`，缺少完整的头像文件名语义。
- `getCharacterNames()` / `getCharacterIds()` / `getCurrentCharacterName()` 未实现。
- 影响：需要读取开场白列表、角色扩展字段或遍历角色库的脚本无法工作。

### 8. 宏与 Slash 命令覆盖有限（低中影响）

- `substitudeMacros` 只替换 `{{char}}` / `{{user}}` / `{{lastMessageId}}` 等少量宏。
- `triggerSlash` 只支持少量内置命令；未知命令不会返回上游的管道结果。
- 影响：依赖 `{{random}}`、`{{time}}`、`{{getvar::...}}` 或复杂 Slash 的脚本结果不准确。

## 本地卡实际用到的缺失 API

扫描 `data/admin/characters` 下 8 张含作者脚本的卡：

| API | 次数 | 卡数 | 说明 |
|---|---:|---:|---|
| `setChatMessages` | 3 | 2 | 红楼去重、约会大作战能力清单 |
| `deleteChatMessages` | 1 | 1 | 约会大作战能力清单 |
| `generate`（全局） | 29 次命中 | 2 | 其中包含注释/能力清单，真实调用主要是 `context.generate` |
| `errorCatched` | 13 | 3 | 滨莲市等卡的启动包裹 |
| `retrieveDisplayedMessage` | 13 | 3 | 读取已渲染楼层的 DOM |
| `getCurrentPersonaName` | 2 | 1 | 读取当前 persona 名 |
| `rebindGlobalWorldbooks` / `rebindCharWorldbooks` / `rebindChatWorldbook` | 各 1 | 1 | 约会大作战能力清单 |
| `builtin` / `replacePreset` | 少量 | 2 | 人工核对为按钮 id / 卡内同名局部函数，误命中 |

## 建议修复顺序

1. **P0**：世界书 API 改为数组语义；`getChatMessages` 支持范围和筛选；`setChatMessages` 最小实现。
2. **P1**：事件 API 返回值/常量值；`injectPrompts` 返回 `{uninject}`；`errorCatched`、`retrieveDisplayedMessage`、`getCurrentPersonaName`。
3. **P1**：`context.generate` 接入主聊天生成，或明确降级并返回可识别的失败。
4. **P2**：变量作用域（global/character/preset/script）、角色读取、`generate` 全局别名。
5. **P3**：preset/persona/regex/audio/file/extension/import_raw。

## 复现命令

在作者 iframe 内执行：

```js
getWorldbook(getCharWorldbookNames('current').primary) // 应为数组
getChatMessages('0-10', { role: 'user' })               // 应返回区间内多条
const r = injectPrompts([{ id: 'x', content: 'x', position: 'in_chat', depth: 0, role: 'system' }])
typeof r.uninject                                       // 应为 function
const e = eventOn('x', () => {})
typeof e.stop                                           // 应为 function
getVariables({ type: 'global' })                        // 不应等于 chat 变量
```
