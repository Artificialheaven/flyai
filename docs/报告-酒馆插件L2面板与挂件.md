# 报告：酒馆插件 L2（面板与挂件）

- 日期：2026-11-25
- 分支：`feature/poc-incremental-update`
- 目标：在不重建 ST 主页面的前提下，让“有 UI 需求”的插件获得**可用的原生界面**：
  - 设置面板（schema 原生渲染 / panel.html 独立面板）
  - 消息区按钮挂件
- 非目标：ST DOM/CSS 仿真（L3，见另一份评估）

## 1. 能力总览

| 能力 | 入口 | 实现 | 安全边界 |
|---|---|---|---|
| Schema 面板 | `flyai.panel = {type:"schema", schema:"panel.schema.json"}` | 设置页用原生表单渲染 | 不执行扩展 HTML；只读写本扩展设置 |
| 独立面板 | `flyai.panel = {type:"iframe", html:"panel.html"}` | 沙箱 iframe（allow-scripts） | CSP `connect-src 'none'`；RPC 仅 settings/toast/popup/log |
| 消息挂件 | `__FLYAI_EXT_HOST__.ui.registerMessageWidget({id,label,command})` | 宿主在每条助手消息操作栏原生渲染按钮 | 点击只执行扩展已注册的 slash 命令 |
| 头部挂件 | `registerHeaderWidget` | 注册已通、UI 预留 | 当前不渲染，避免占用会话头部 |

## 2. Schema 面板

安装时读取 `panel.schema.json`（≤512KB，必须在包内、禁止穿越），
`GET /api/extensions/{name}/panel` 返回 `{type,path,url,schema}`。

前端 `SchemaSettingsForm` 支持的 JSON Schema 子集：

- `object.properties`
- `string` / `number` / `integer` / `boolean`
- `enum` → 下拉框
- `array`（字符串数组） → 多行文本，一行一项
- `format: textarea` 或 `ui.widget: textarea` → 多行
- `title` / `description` / `default` / `minimum` / `maximum`

编辑后仍以扩展命名空间写入 `/api/extensions/{name}/settings`，刷新/换设备保留。
没有 schema 时，管理面板仍提供原始 JSON 编辑作为兜底。

示例（fixture `logic-panel`）：

```json
{
  "type": "object",
  "properties": {
    "enabled": { "type": "boolean", "title": "启用", "default": true },
    "greeting": { "type": "string", "title": "问候语", "maxLength": 200 },
    "limit": { "type": "integer", "title": "上限", "minimum": 1, "maximum": 100 },
    "mode": { "type": "string", "title": "模式", "enum": ["a", "b"] }
  }
}
```

## 3. 独立面板（panel.html）

- `panel.html` 由后端静态路由提供，前端在父页面 fetch 后包进宿主文档；
- 面板内可用标准 `extension_settings` / `saveSettingsDebounced`（500ms 防抖）、`toastr`、`Popup`；
- 面板 iframe 与扩展主 iframe 隔离，但共享同一扩展设置命名空间；
- 不允许：跨域 fetch、访问父页面 DOM、读写其他扩展设置、读取密钥；
- 保存后同步回管理面板详情与扩展主 iframe（下次启动生效）。

## 4. 消息挂件

扩展在入口脚本里：

```js
const H = window.__FLYAI_EXT_HOST__;
H.ui.registerMessageWidget({
  id: 'translate',
  label: '翻译',
  title: '把这条回复翻译成中文',
  command: '/translate-last',
});
```

宿主把它登记为 `{ext, slot:'message', id, label, command}`，在每条助手消息底部
渲染原生小按钮；点击时向该扩展发送 `slash.execute`，由扩展自己实现命令。
挂件随扩展停用/销毁自动清理，不残留。

## 5. 安全与权限

- schema 面板不执行 HTML，纯 React 渲染；
- panel.html 与扩展主代码同等级沙箱，CSP 禁止外网；网络仍走宿主 `net.fetch`（需 `net` 能力 + 管理员开关）；
- 所有面板/挂件 RPC 经过能力表校验；
- 设置上限 1MB/扩展，读取失败回退空对象，不阻塞加载。

## 7. 未实现 / 后续

- 头部挂件 UI 未渲染（注册接口已就绪）；
- 面板内文件上传/媒体选择、消息内容改写、富文本编辑器未提供；
- 消息挂件只支持“执行命令”，不支持自定义 HTML 渲染；
- schema 仅覆盖常用子类型，复杂 `oneOf/anyOf/$ref` 未支持；
- 真机/真实浏览器尚未手工冒烟（逻辑已在 happy-dom 验证）。

## 8. 使用建议

- 新扩展优先用 **schema 面板**（零 HTML、移动端一致）；
- 需要复杂交互再用 `panel.html`，并只在面板内做设置类操作；
- 消息区交互用挂件 + slash，命令实现在扩展内，便于诊断与复用；
- 扫描为 L3 的扩展仍不加载；需要其 UI 的，参见 L3 评估中的“兼容壳”方案。
