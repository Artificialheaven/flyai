# FlyAI · 类酒馆 AI 聊天工具（支持工具调用）

一个本地的 Web 端 AI 聊天工具，类似 SillyTavern（酒馆）。

- 支持接入任意 **OpenAI 兼容协议** 提供商（DeepSeek、Kimi、Qwen、中转站等）及 **Anthropic 原生** 提供商。
- **流式"思考 & 对话"**：模型的思考过程和正式回复分别流式展示。
- **断线重连**：生成过程在后台任务中进行、事件带序号全量缓存——回答中刷新页面会自动打开会话并回放续读，网络抖动时指数退避自动重连；点「停止」已生成的半截回复照样保存。
- **AI 自主工具调用**：模型可通过 function calling 自行调用工具获取信息（如读取文件、查询角色/世界观内容表），多轮循环直到给出最终答复。
- **角色卡 + 世界观**：为角色设定头像/简介/经历/内容表，为世界观设定内容/内容表；AI 扮演角色并通过统一工具 `query_lore` 自行查询内容表。
- **角色扮演对话格式**：默认规范——动作用 `（ ）`、内心活动用 `_…_`、对白用 `「」`；不同类型自动分段并以不同颜色/斜体区分展示。
- **属性跟踪**：可开启后由 AI 在每回合结束时调用工具 `update_attributes` 增减角色属性（好感度、金钱等，可在设置中开关 / 选择是否由 AI 自行提供数值），实时显示在顶栏。
- **亮/暗主题**：扁平化界面，可一键切换。
- **手机端适配**：窄屏下侧栏收为抽屉式菜单，触控友好的现代化界面。
- **多用户 + 管理员**：独立登录页（不登录不能进），登录签发随机 Bearer 令牌（7 天有效、可吊销，服务端持久化到 data/ 下，重启/刷新不掉登录态）+ 失败 5 次锁定 5 分钟防爆破；管理员凭据写在 `config/config.json` 的 `auth.admin`（无默认用户），普通用户由管理员创建、不能自助注册，管理员可重置用户密码（重置即踢出其全部会话）；角色卡/世界观/会话按用户隔离。
- **本地 Stable Diffusion 引擎**：可一键切换为使用本机 SD WebUI（Anything V5，走 Gradio API、无需 `--api`）；提示词与全部采样参数由内置 AI 自动生成。
- **AI 浏览器（Playwright）**：AI 可像人一样有状态地逐级浏览网页——打开页面 → 读取带编号的链接/按钮/输入框 → 点击进入内部页面或填表搜索，直到找到目标内容。可选依赖，默认关闭。
- **语音合成（豆包语音大模型 · 朗读）**：用户要求朗读/语音时 AI 自动调用 `text_to_speech` 工具，音频在消息内以独立语音条展示（播放/暂停、点击进度条跳转、时长、下载），页面内多条语音互斥播放。
- **全屏看图器**：点击对话任意图片放大，可下载、按生图方式查看提示词（SD 展示正/负向标签与采样参数，云端展示完整提示词）。
- **导出/导入**：角色卡与世界观可导出为 JSON 文件备份或分享，也可一键导入。
- **插件化扩展**：工具以目录式插件提供，可自行添加（见 `plugins/README.md`）。

> 📖 **详细使用教程**（含如何写出完善的角色卡与世界观）：见 [`docs/使用教程.md`](docs/使用教程.md)。

## 运行

```bash
# 使用项目内 venv（Python 3.9.13）
.venv\Scripts\pip install -r requirements.txt

# 启动
.venv\Scripts\python main.py
# 或
.venv\Scripts\python -m uvicorn flyai.app:app --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000>。

首次启动会自动从 `config/config.example.json` 生成 `config/config.json`。
在页面右侧「⚙️ 设置」中添加/编辑提供商（填好 API Key）、切换激活提供商、配置工具白名单目录。
左侧「🧩 内容」中新建角色卡与世界观；在会话顶栏选择当前会话要扮演的角色 / 采用的世界观。

## 角色扮演与内容查询

- **角色卡**：头像（可上传）、简介、经历、**对话范例 mes_example**、以及一张内容表（标题+内容，AI 主动查询）。
- **对话范例（few-shot）**：填 3~5 轮范例对白，轮间单独一行写 `<START>`，可用 `{{char}}`/`{{user}}` 占位。注入时明确告知 AI「范例剧情并未真实发生，仅供模仿语气」，避免范例污染剧情。这是维持原创角色语气的关键手段。
- **常驻条目（pinned）**：内容表条目勾选「常驻」后无条件注入系统提示词，等同 SillyTavern 世界书的 Constant——防止 AI 一直不调用 `query_lore` 时关键设定形同虚设。
- **世界观**：总体内容 + 一张内容表（同样支持常驻条目）。
- 会话顶栏下拉选择角色与世界观后，系统提示词会自动注入角色人设与世界观。
- AI 需要细节时可通过 `query_lore(kind='character'|'world', keyword=…)` 查询内容表：标题+正文多词打分（标题精确/子串加权），配置语义嵌入时先做带相似度门槛（默认 0.55）的向量检索，不达标自动回退关键词；结果有上限（默认 8 条）、有排序；表向量按内容签名缓存，不重复计算。
- **注入预算**：「⚙️ 设置 → 角色扮演」可给简介/经历/世界观/对话范例/常驻条目分别设字符预算，**默认全部 0=不限（行为与旧版一致）**。超预算时按段落、整轮丢弃（绝不截半轮），末尾标「…（下略）」。
- **内置要求展示**：新建/编辑角色卡或世界观时，「对白格式要求」「工具使用要求」两个文本框会自动填入内置默认（来自 `roleplay.format_instruction` / `roleplay.tool_instruction`），可逐卡覆盖；留空则遵循全局默认。填写的值会注入该系统提示词。
- 弹窗支持点击空白处关闭；若表单有未保存修改会先弹出确认。

## 对话压缩（先 diff 确认，后写入）

- 顶栏「☁ 压缩」让 AI 把对话历史归纳进角色卡/世界观。**现在只生成提案**：弹窗内展示逐项 diff（新增/更新/未变折叠，未变条目数与常驻数可见），确认前不写任何数据，放弃即无任何改动。
- 点「✓ 确认写入」后才写入**当前会话副本**（库主卡不受影响）；若提案生成后设定又被改过（409），提案作废需重新压缩。
- 内容表**按标题合并**：AI 只给需要更新的标题、新设定用新标题追加，漏列的条目原样保留、不会因省略而丢失；常驻标记只增不减。
- 写入后才能下载压缩包，单 AI 会话还可把角色卡发布回角色库；细改可在写入后用会话副本编辑器完成。

## 对话格式与属性跟踪

- **对话格式（可开关）**：在「⚙️ 设置 → 角色扮演」中启用。默认要求 AI 用 `（ ）` 描述动作、用 `_…_` 标记内心（下划线外侧不贴字母数字）、用 `「」` 表示对白，并以空行分段；前端会把对白（彩色）、动作（斜体灰）、内心活动（彩色斜体）区分展示。
- **属性跟踪（可开关）**：在设置中定义属性列表（如好感度、金钱，含初始值/上下限）。启用后 AI 在每回合结束时调用工具 `update_attributes` 提交本回合的增减量，顶栏会显示最新数值。可关闭「由 AI 自行提供」使其仅作展示。
- 相关配置位于 `config/config.json` 的 `roleplay` 节点（`format_enabled`、`format_instruction`、`attributes`、以及 5 个 `*_chars` 注入预算，预算默认 0=不限）。
- 语义检索参数在 `embeddings` 节点：`score_threshold`（默认 0.55）、`keyword_limit`（默认 8）。

## 云端图生图（单张 / 多张参考图）

`edit_image` 工具以对话中已有图片为参考调用 Seedream：

- **单张参考**：改风格、换装、改表情动作、局部修改、画面延展；`image` 省略时自动取最近一张。
- **多张参考（最多 14 张）**：换装（图1人物 + 图2服装）、人物放进指定场景、融合特征等。`image` 传路径数组，或省略路径并给 `image_count` 自动从历史收集最近 N 张（用户上传图与已生成图都算）。
- AI 在 prompt 中用「图1」「图2」逐张说明用途，图片顺序与编号严格一致；历史不足指定张数直接报错，不静默少图。

## 联网搜索与分页抓取

- `web_search(query)` 返回编号的结果列表（标题/URL/摘要），AI 自行挑选相关链接。搜索执行方式默认为 **Chromium 引擎**：Bing 优先走 **RSS 数据接口**（`&format=rss`，httpx 直连干净 XML、不启动浏览器），RSS 失败自动回退真实 Chromium 渲染（需 Playwright）；也可整体改用 httpx 直连。搜索引擎支持 **Bing**（默认）与**百度**（仅 Chromium，`link?url=` 跳转链自动解包，遇验证码自动回退 Bing）。
- `web_fetch(url)` 抓取单页并整理为 markdown。**长页面分页读取、不丢后半部分**：每次返回约 `max_page_chars`（默认 6000）字，头部标明区间与总字数；需要后续内容时用相同 URL 加 `offset=6000`、`offset=12000`… 继续读，直到提示已到末尾。抓取的完整正文在服务端短缓存（10 分钟），翻页不重复下载；offset 超出总长度会明确报错。
- **联网工具轮数独立**：`web_search`/`web_fetch` 拥有专属轮数预算（默认 15，设置中可调，1–50），与通用工具轮数（8）分开计数、互不占用；用满 N 轮后 AI 仍可直接给出最终回答，只有再次发起同类调用时才拦截。

## AI 浏览器（Playwright，逐级进入网页）

可选功能，AI 通过一组共享浏览器会话的工具像人一样操作真实浏览器：

- **`browser_open(url)`**：打开页面，返回快照（标题/URL + 编号元素 + 正文）。
- **`browser_click(target)`**：点击编号对应的链接/按钮；进入内部页面后自动返回新快照，`target=_blank` 自动切换新标签。
- **`browser_type(target, text, submit=true)`**：向输入框填字并可直接回车提交（搜索→结果页→点详情的标准流程）。
- **`browser_back()` / `browser_get_text()` / `browser_close()`**：后退、只取当前页正文、关闭会话。

会话按「用户 + 聊天会话」隔离复用，隐身上下文不共享 cookie；空闲自动回收标签页，动作数有上限。安全上对**页面与 JS 发出的每一个请求**做 SSRF 拦截（内网/本机地址拒绝），并自动屏蔽图片/字体等无用资源加速渲染。

安装（Python 3.9 支持；Windows / Ubuntu 均可，无头模式无需桌面环境）：

```bash
pip install -r requirements-browser.txt
playwright install chromium
# Ubuntu 另需系统库：
sudo playwright install-deps chromium
```

在「⚙️ 设置」中勾选启用，保存后立即生效（浏览器在首次使用时自动启动）。

## 本地 Stable Diffusion（Anything V5）

- 管理员在「⚙️ 设置 → Stable Diffusion」启用并确认 WebUI 地址（默认 `http://127.0.0.1:7860`）。
- 对话输入区出现「SD」按钮：点亮走本地 SD、熄灭走云端生图模型；选择持久化保存。
- 点亮时 AI 画图，由**内置提示词 AI** 生成全部内容：英文 danbooru 标签提示词、负向提示词，
  以及宽高 / 步数 / CFG / 采样器与调度器 / 种子等全部参数；
  缺失或越界的参数自动回落到设置中的兜底默认。
- 直接经 Gradio API（`/config` + `/api/predict` + `/file=`）调用，WebUI 无需加 `--api`；
  更换 WebUI 版本导致 fn_index 变化时，可在设置中修改。

## 语音合成（豆包语音大模型 · 朗读）

用户说「朗读一下 / 用语音说 / 念出来」时，AI 自动调用 `text_to_speech` 工具把文本合成语音，音频在 AI 消息内以**独立语音条**展示：播放/暂停、点击进度条跳转、时长显示、下载；同一页面播放新语音会自动暂停其他语音。

- 在火山引擎控制台开通「豆包语音合成」，在「⚙️ 设置 → 语音合成」填写 API Key；
- 默认资源版本 `seed-tts-2.0`（只能调用 2.0 音色），默认音色 `S_BcqE5org2`，音色授权以控制台为准；
- **音色清单**：管理员在设置中维护「显示名 + 音色 ID」清单，作为角色卡下拉绑定的数据源（清单不强制校验，默认音色允许填清单外 ID）；
- **角色卡绑定音色**：编辑角色卡时可从清单中选择一个绑定音色；未绑定的角色使用全局默认音色。合成时音色解析顺序 = AI 显式指定 → 角色卡绑定 → 默认音色（AI 仍可在对话中临时换音色）；
- **权限等级**：可设置语音合成最低权限等级（0=不限制，0–255；管理员恒可用）。等级不足的用户工具仍可见，但调用会被拒绝并收到中文提示；
- 音频格式默认 mp3；ogg_opus 存为 `.ogg`；pcm 会在服务端自动封装为 `.wav`；
- 代理仅支持 HTTP（`http://host:port`，走 CONNECT），留空为直连；
- 保存配置后**立即生效**，无需重启。依赖 `websockets`（已在 requirements.txt）。

## 手机端

窄屏（≤860px）时左侧会话列表自动收为抽屉式菜单，点顶栏 ☰ 打开；对话框与表单单列堆叠，适配安全区，触控目标加大。

## 目录结构

```
flyai/
├── main.py                 # 启动入口
├── config/                 # 配置（config.example.json 入库；config.json 含 key 不入库）
├── plugins/                # 插件目录（内置 file_reader + 开发文档）
├── workspace/              # 文件读取默认白名单目录
├── flyai/                  # 应用包
│   ├── app.py              # FastAPI 装配
│   ├── config.py           # 配置模型
│   ├── schemas.py          # 内部统一消息模型
│   ├── providers/          # OpenAI 兼容 / Anthropic 适配器
│   ├── agent/loop.py       # agentic 工具调用循环
│   ├── tools/              # 工具基类 / 注册表 / 插件加载器
│   ├── sd/                 # 本地 Stable Diffusion 引擎（内置提示词 AI + Gradio 客户端）
│   ├── sessions/           # 会话存储（memory / json）
│   └── web/static/         # 前端单页（无构建）
└── tests/                  # 编解码与安全单测
```
