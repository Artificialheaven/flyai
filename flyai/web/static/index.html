联网搜索

AI 先搜索得到结果列表，自行判断相关性，再用网页抓取工具读取选定页面。国内直连 Bing，无需代理。

AI 浏览器（Playwright）

AI 可像人一样逐级浏览网页：打开 → 查看编号元素 → 点链接/按钮进入内部页面。需先安装：pip install -r requirements-browser.txt 然后 playwright install chromium（Ubuntu 另需 sudo playwright install-deps chromium）。未装时勾选也无法使用。
