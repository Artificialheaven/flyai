联网搜索

联网搜索

AI 先搜索得到结果列表，自行判断相关性，再用网页抓取工具读取选定页面。国内直连 Bing，无需代理。

AI 浏览器

AI 浏览器（Playwright）

AI 可像人一样逐级浏览网页：打开 → 查看编号元素 → 点链接/按钮进入内部页面。需先安装：pip install -r requirements-browser.txt 然后 playwright install chromium（Ubuntu 另需 sudo playwright install-deps chromium）。未装时勾选也无法使用。

朗读音色

语音合成（豆包语音大模型 · 朗读）

用户说「朗读 / 用语音说 / 念出来」时，AI 自动调用工具生成语音，消息内以独立语音条播放。需在火山控制台开通对应服务并填写 API Key（音色授权以控制台为准）。可在此维护音色清单供角色卡绑定，并设置使用语音合成的最低权限等级。保存后立即生效。

Galgame 模式

Galgame 模式

单角色视觉小说：AI 绘制背景与立绘、分句打字机回放、对白语音、选项推进。Galgame 会话一轮内可能多次调用工具（绘图/切换/选项），需更大的工具轮数预算。

服务协议

欢迎使用 FlyAI。本服务部署在站点管理员自有的服务器上，你的对话内容、角色卡、世界观条目与生成的图片均存储在该服务器，请自行做好备份。

你需对自己账户下的全部行为与内容负责，不得利用本服务从事违反法律法规的活动。请妥善保管账户密码，不要将登录凭据透露给他人。

AI 生成的内容可能存在错误或偏见，请仔细甄别并自行判断其准确性与合法性。
